断链是指：**让条件制约的命令方块控制后续所有命令方块是否执行**——条件成立就把链接上，不成立就让链断在那里。它是基岩版命令方块里最常用的一种条件过滤结构，最直接的作用是省性能。

### 原理

断链要解决的是：让一个条件制约的命令方块，控制它后面整条链跑不跑。

做法是在链中间放一块**平时不指向后续链**的方块（③）。条件成立时，前面那块条件制约的方块（②）先把它转向后续链，链路接通，信号才能往下传；条件不成立时 ② 不执行，③ 保持原朝向，链就终止在 ③ 这里。

具体过程：

1. ① 执行检测，成功则触发 ②。
2. ② 是条件制约，命令只有一句：用 `setblock` 把 ③ 转向后续链。②③ 在这里约等于扮演红石比较器的角色——检测成功则允许后续命令执行。
3. ③ 转向后指向后续链，后续命令依次执行。
4. 执行完把 ③ 转回原来的朝向，下次重新由 ② 转向。

伪代码即：

```text
if 检测成功:
    把 ③ 转向后续链
    执行后续命令
    把 ③ 转回
```

条件失败时，链终止在指向别处的 ③ 上，后面一条都不执行。这也是它省性能的地方：**后续命令不必每条都自带一遍条件，条件不成立时连解析都不做。**

<CmdChat>`/gamerule maxcommandchainlength`

可以查当前的单链执行上限，默认 65536，被设成 0 时链完全不执行。

### 结构

三块方块，位置固定，朝向要按自己的摆法算：

```
① 循环方块           ② 条件制约的连锁方块              ③ 一个朝向别处的连锁方块
   每刻执行检测   →     命令：setblock 改 ③ 的朝向   →     平时不指向后续链，信号到此为止
                                                                  ↓ 把 ③ 转向这里
                                                        ④ ⑤ ⑥ … 实际要执行的命令
```

- **①** 重复命令方块，保持开启、延迟 0，命令写 `execute if entity <条件>` 这类检测。
- **②** 必须设成**条件制约**，命令只有一条：`setblock <③的坐标> chain_command_block ["facing_direction"=<朝向后续链>]`。
- **③** 只负责通断，命令可以是空的，不要往里写业务命令。

②③ 在这里约等于扮演红石比较器的角色：检测成功则允许后续命令执行，检测失败则保持断开状态而不允许后续命令执行。

### 断开之后要转回去

如果 ③ 一直被留在接通状态，下一轮检测成功时链就自动通了，断链退化成普通的循环链——条件持续成立，后面的命令每刻重复执行。

所以链尾要把 ③ 转回断开：在 ④⑤⑥ 的最后加一条 `setblock <③的坐标> chain_command_block ["facing_direction"=<断开方向>]`，或者把 ② 重置成默认姿态。

断链本质上是「检测-循环链」的写法，想让它只执行一次，就必须自己关门。

### 与红石比较器的区别

| | 红石比较器 | 断链 |
|---|---|---|
| 条件失败时挡住后续 | 能 | 能 |
| 额外延迟 | +2 游戏刻 | 0 |
| 方块数 | 1 比较器 + 红石粉 | 2 个命令方块 |
| 搭错的表现 | 电路可查 | 静默不通、不报错 |
| 适合 | 对延迟不敏感 | 每刻都在跑的循环链 |

### facing_direction 取值

| 值 | 朝向 |
|----|------|
| 0 | 下 |
| 1 | 上 |
| 2 | 北（z−） |
| 3 | 南（z+） |
| 4 | 西（x−） |
| 5 | 东（x+） |

写法：`chain_command_block ["facing_direction"=2]`。

不要照抄别人的数值。闸门朝哪、后续链在哪个方向，取决于自己的摆法，抄错一个方向整条链静默断开。

### 六个失效点

1. **③ 没转回去** → 退化成循环链，每刻刷屏。
2. **朝向算错** → 链静默断开，不报错，只表现为没反应。
3. **② 不是条件制约** → 检测失败也执行，条件形同虚设。
4. **③ 上写了业务命令** → 被 `setblock` 重设时可能清空，闸门只做通断。
5. **链跨区块** → 区块卸载后整条链停摆，命令方块区要加 `/tickingarea`。
6. **`/clone` 复制这套结构** → 朝向跟着复制源走，相对位置变了要重新对向。

### 示例

用一个检测 + 一长串动作的结构举例：玩家踩上压力板后连续执行五条初始化命令。

<CmdRepeat>`/execute if entity @a[x=100,y=64,z=100,r=2]`

<CmdChain>`/setblock 110 64 100 chain_command_block ["facing_direction"=5]`

<CmdChain>`/tp @a[x=100,y=64,z=100,r=2] 200 70 200`

<CmdChain>`/gamemode adventure @a[x=200,y=70,z=200,r=5]`

<CmdChain>`/title @a[x=200,y=70,z=200,r=5] title §l§b进入副本`

<CmdChain>`/playsound random.levelup @a[x=200,y=70,z=200,r=5]`

<CmdChain>`/setblock 110 64 100 chain_command_block ["facing_direction"=1]`

第一条每刻检测有没有玩家站到入口；有就由第二条把闸门转向东侧，后面四条依次执行，最后一条把闸门转回朝上（断开）。玩家离开后整段不再执行，五条命令一次解析都不用付。
