一条命令就是一行文本，由命令名和若干参数组成。真正容易出错的不是命令名，是参数——每一段都有固定类型，写错一段整条命令失败，且不会部分生效。

### 原理

游戏解析一行命令时，先拆成命令名和参数，再按这条命令自己的语法逐段校验。参数类型分六种：选择器、坐标、整数、浮点数、字符串、枚举。类型不符直接拒绝，不会"尽力执行"。

**选择器在执行瞬间求值**。`@a` 不是"所有玩家"这个静态概念，而是"此刻在线、且满足方括号里全部条件的玩家"。同一行 `@a` 在不同时刻、不同维度匹配到的对象可能完全不同。

**坐标同样在执行时解析**。`~ ~1 ~` 的基准是执行位置，不是玩家脚下。用 `/execute` 换了执行位置，同一个 `~ ~1 ~` 就指向别处——这正是命令能被复用的原因。

### 语法约定

| 符号 | 含义 |
|------|------|
| `<参数>` | 必填 |
| `[参数]` | 可选 |
| `a\|b` | 二选一 |

例：`/give <玩家> <物品> [数量] [数据] [组件]`，前两段必填，后三段可选。

### 目标选择器

五个基本变量：

| 变量 | 含义 |
|------|------|
| `@p` | 最近的玩家 |
| `@a` | 所有玩家 |
| `@r` | 随机一名玩家 |
| `@s` | 执行者自己 |
| `@e` | 所有实体 |

另外三个：

| 变量 | 含义 |
|------|------|
| `@n` | 最近的实体（1.21.100 起） |
| `@initiator` | 与 NPC 对话的玩家，只在 NPC 交互里有效 |
| `@v` | 所有玩家，`@a` 的旧写法 |

### 选择器参数

方括号里可以写多个参数，用逗号分隔，**全部满足才算匹配**。

#### 位置与体积

| 参数 | 作用 | 例子 |
|---|---|---|
| `x` `y` `z` | 设定判断的起点，默认是执行位置 | `@a[x=100,y=64,z=100]` |
| `dx` `dy` `dz` | 以起点为角的长方体尺寸，边长是 \|d\|+1 | `@a[x=0,y=0,z=0,dx=5,dz=5]` |
| `r` | 最大距离 | `@a[r=10]` |
| `rm` | 最小距离 | `@a[rm=5]` |

`dx/dy/dz` 注意两点：一是边长是绝对值加一，写 `dx=5` 覆盖 6 格；二是 1.19.70 之后判断的是**判定箱与长方体相交**，不再是"脚部坐标落在框内"，所以高个子实体的上半身也会被选中。

#### 数量与排序

| 参数 | 作用 |
|---|---|
| `c` | 最多选几个。正数取最近的 N 个，负数取最远的 N 个 |

`@p[c=3]` 是最近的 3 名玩家，`@p[c=-4]` 是最远的 4 名。`c` 与 `r` 同时写时先按距离筛，再计数。

#### 玩家状态

| 参数 | 作用 | 例子 |
|---|---|---|
| `m` | 游戏模式，自动排除非玩家 | `@a[m=creative]`、`@a[m=1]`、`@a[m=!spectator]` |
| `l` / `lm` | 经验等级的上限 / 下限 | `@a[lm=5,l=15]` |
| `name` | 名字完全匹配 | `@a[name=Alex]` |
| `tag` | 计分板标签，写两次表示两个都要有 | `@a[tag=admin,tag=online]` |
| `scores` | 计分板分数落在范围内 | `@a[scores={金币=100..}]` |
| `hasitem` | 物品栏里有指定物品 | `@a[hasitem={item=diamond,quantity=3..}]` |
| `haspermission` | 权限状态 | `@a[haspermission={movement=disabled}]` |

`scores` 的值支持区间：`3` 恰好、`3..` 至少、`..5` 至多、`3..5` 之间、`!0` 不等于 0。

`hasitem` 的方括号里是一个或多个条件对象，字段是 `item`、`quantity`（默认 `1..`）、`location`、`slot`。写多个对象时全部满足：

`@a[hasitem=[{item=diamond,quantity=3..},{item=stick,quantity=2..}]]`

`quantity=0` 表示"没有这件物品"，`quantity=0..` 表示这一项不做筛选。

#### 实体类型

| 参数 | 作用 | 例子 |
|---|---|---|
| `type` | 实体 ID | `@e[type=zombie]` |
| `family` | 实体族 | `@e[family=pacified]` |
| `has_property` | 实体属性 | `@e[has_property={minecraft:is_baby=true}]` |

`type` 可以取反：`@e[type=!player]` 是所有非玩家实体。

#### 朝向

| 参数 | 作用 |
|---|---|
| `rx` / `rxm` | 垂直角的上限 / 下限，抬头为负 |
| `ry` / `rym` | 水平角的上限 / 下限，0° 朝正南 |

`@e[rxm=45]` 是看向地平线偏下 45° 及更低的目标。角度区间是闭区间，必须"最小在前、最大在后"，写反了不报错，只是永远匹配不到。

### 组合与取反

- 逗号分隔即"并且"：`@e[type=zombie,r=10]` 是 10 格内的僵尸。
- 同一参数写两次也是"并且"：`@a[tag=a,tag=b]` 要求两个标签都有。
- 值前加 `!` 取反：`@a[m=!creative]`、`@e[type=!player]`。
- 数值支持 `..` 区间：`@a[l=..9]`。
- 名字带空格时要用引号：`@a[name="Steve Jobs"]`。

选择器匹配不到任何目标时，整条命令判定为失败——这一点在命令方块里很有用，条件方块的判定就靠它。

### 坐标系统

| 形式 | 写法 | 基准 |
|---|---|---|
| 绝对 | `100 64 100` | 世界原点 |
| 相对 | `~ ~1 ~` | 执行位置 |
| 局部 | `^ ^ ^1` | 执行位置 + 朝向，`^1` 是正前方一格 |

局部坐标的三个轴跟着视角转：`^ ^ ^1` 永远指向视线正前方，`^1 ^ ^` 指向右手边。

<CmdChat>`/setblock ~ ~-1 ~ diamond_block`

在脚下放一块钻石块。

<CmdChat>`/fill ~-5 ~-1 ~-5 ~5 ~-1 ~5 stone`

以自己为中心铺 11×11 的石头地板。

<CmdChat>`/execute as @a at @s run summon armor_stand ^ ^ ^2`

在每个玩家视线前方两格生成一个盔甲架。这里的 `^` 基于玩家朝向，不是世界坐标轴。

### 常见错误

| 现象 | 原因 |
|---|---|
| 命令没反应也不报错 | 选择器匹配到 0 个目标，多数命令会静默失败 |
| `@a[r=10]` 选不到人 | `r` 是最大距离，起点默认执行位置；从命令方块执行时起点在方块上 |
| 角度条件永远不命中 | `rx` 是上限、`rxm` 是下限，写反了 |
| `dx=5` 只覆盖 5 格 | 边长是 \|d\|+1，`dx=5` 是 6 格 |
| 名字带空格匹配不到 | 需要 `name="Steve Jobs"` |

全部命令列表可以用 `/help` 查看。
