命令方块是把聊天栏里的命令改成自动执行的方块。它有三个可选项——方块类型、条件、红石——加一个基岩版独有的延迟刻数，组合起来决定一条命令**什么时候跑、跑不跑、跑几次**。链则是把多个方块串起来，让它们在同一个游戏刻内按顺序跑完。

### 原理

命令方块被激活时，做三件事：判断自己该不该执行、执行命令、把信号传给箭头指向的下一个方块。

**方块类型**决定触发方式：

| 类型 | 颜色 | 行为 |
|---|---|---|
| 脉冲 | 橙 | 每次被激活执行一次 |
| 连锁 | 青 | 只在指向它的方块被执行后执行 |
| 重复 | 紫 | 保持激活时每游戏刻执行一次 |

**条件**决定执行前要不要看前一个方块的结果：

- **条件制约**：只有背后（箭头反方向）那个方块上一次成功执行，自己才执行。
- **不受制约**：不管前一个成没成功，自己都执行。

要注意条件制约只影响它自己。它不执行时，信号照样往下一个方块传，后面的无条件方块照跑。想让一个条件控制整段链，得让链本身断开：中间放一块平时朝别处的方块，条件成立时由前一个方块用 `setblock` 把它转向后续链，条件不成立就让它继续朝着空地——这就是「断链」。

**红石**决定要不要外部供电：`需要红石` 必须收到红石信号，`保持开启` 则一直处于激活状态。连锁方块默认就是保持开启。

**延迟刻数**是基岩版独有的。对脉冲和连锁方块，它是"被触发后等 N 刻再执行"；对重复方块，它是"最快每 N 刻执行一次"。另有一个 `执行第一个已选项`（Execute on First Tick），只对重复方块有效：开启时激活后立刻执行一次，关闭时等满延迟才第一次执行。

1 秒约等于 20 游戏刻，所以延迟 20 就是一秒一次。

### 链的执行顺序

一个方块执行完（无论成功失败），会向箭头指向的连锁方块发信号。连锁方块接着执行，再往下传。

这条链在**同一游戏刻内**跑完，顺序就是连接顺序。但有一个限制：信号传不到本刻已经执行过的方块，所以链是单向的，绕不回来。

摆放时，后一个方块的箭头必须接在前一个方块的箭头头部，也就是方块正前方。方向接错不会报错，只会表现为"后面那些方块没反应"。

### 输出

命令方块执行完有两个输出：

- **成功次数**：背对它的红石比较器可以读到，强度等于成功次数（超过 15 截断）。基岩版里成功次数与命令有关，比如影响到的玩家数、改动的方块数。
- **上一段输出**：方块界面里显示的文字，成功是白字，失败是红字或 0。排查时先看这里。

<CmdChat>`/gamerule commandblockoutput false`

关掉命令方块往聊天栏刷的输出。

<CmdChat>`/gamerule sendcommandfeedback false`

关掉命令执行后返回给玩家的反馈。

### 示例

**放钻石块换绿宝石**：三个方块串成一条链，检测位置上有钻石块，就给最近的玩家一颗绿宝石，并打上标签防止重复发放。

<CmdRepeat>`/execute if block 0 4 0 diamond_block`

<CmdChain>`/execute if entity @p[tag=!placed_block]`

<CmdChain>`/give @p emerald`

<CmdChain>`/tag @p add placed_block`

第一条是重复方块，保持开启、延迟 0，每刻检查一次；后三条是条件制约的连锁方块，只有前一条成功才继续。玩家把钻石块放到 `0 4 0` 之后，绿宝石只发一次——因为第四条给玩家打了标签，第二条的 `tag=!placed_block` 就不再匹配。

**一秒一次的计时器**：

<CmdRepeat>`/scoreboard players add 计时 时间 1`

方块类型重复、保持开启、延迟 20。`计时` 是假名玩家，不是真实玩家，专门用来存全局计数。

### 基岩版注意

- `延迟刻数` 与 `执行第一个已选项` 是基岩版独有的，Java 版没有这两个字段。
- 命令方块里的命令**不写前导斜杠**，写了也不报错。
- 命令方块有权限等级，能执行玩家自己没有权限执行的命令，但受限于方块本身可用的命令集——`/op`、`/deop`、`/kick` 这类无法在方块里执行。
- 方块必须在已加载区块里才会运行，玩家走远后区块卸载，链就停了。用 `/tickingarea` 划常加载区。
- `maxcommandchainlength` 决定单次连锁能跑多少个方块，默认 65536，被改成 0 时链完全不执行。
- 用 `/clone` 复制命令方块会连同里面写的命令和设置一起复制，但朝向也一起复制，摆到新位置后相对方向可能全错。
