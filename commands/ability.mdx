### 语法

`/ability <玩家> <能力> true|false`
设置玩家的能力状态

`/ability <玩家> <能力>`
切换玩家的能力状态

### 参数

- `<玩家>` — 玩家类型的目标选择器。指定要赋予或撤销能力的目标玩家。必须为玩家名或玩家类型的目标选择器（如 `@p`、`@a`、`@s`）
- `<能力>` — 枚举类型。指定要操作的能力名称
- `true|false` — 指定是否启用该能力。`true` 为启用，`false` 为撤销。

### 能力名称

| 能力 | 说明 |
|------|------|
| `worldbuilder` | 建造能力，允许玩家编辑世界 |
| `mayfly` | 飞行能力，允许玩家飞行 |
| `mute` | 禁言，开启后其他玩家将无法看见或听见目标的聊天消息 |

### 示例

```mcfunction
/ability @a mute true
```

将所有在线玩家设为禁言状态，聊天消息对其他玩家不可见。

```mcfunction
/ability @p mayfly true
```

给最近的玩家赋予飞行能力，使其在非创造模式下也能飞行。

```mcfunction
/ability Steve worldbuilder false
```

撤销玩家 Steve 的世界建造者能力，限制其对世界的编辑权限。

```mcfunction
/ability @a mute
```

根据当前状态切换所有玩家的禁言状态

> [!NOTE]
> - 玩家退出游戏后，所有的能力均被撤销。
> - 使用 `@a` 等批量选择器时，命令会对所有选中的玩家分别执行，返回成功次数
> - 需要 OP 等级 1
