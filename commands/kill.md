清除（杀死）指定实体。对玩家造成致命伤害，对生物直接移除。

### 语法

`/kill [目标]`

### 参数

- `[目标]` — 目标选择器（默认执行者自己）

### 示例

**清除所有僵尸：**
```mcfunction
/kill @e[type=zombie]
```

移除世界中所有僵尸实体，不产生掉落物和死亡动画。

**清除所有掉落物：**
```mcfunction
/kill @e[type=item]
```

移除地上所有掉落物，常用于清理 lag 来源。可与 [`/clear`](../clear/) 配合清理玩家背包中的物品。

**清除除玩家外的所有实体：**
```mcfunction
/kill @e[type=!player]
```

移除所有非玩家实体，包括怪物、掉落物、经验球等，玩家不受影响。

**清除自己：**
```mcfunction
/kill
```

对自身造成致命伤害，玩家死亡并显示死亡信息。

**清除带有特定标签的实体：**
```mcfunction
/kill @e[tag=cleanup]
```

移除所有带有 `cleanup` 标签的实体。常与 [`/tag`](../tag/) 配合，在地图制作中批量清理临时实体。

### 基岩版注意

- `/kill` 对玩家造成致命伤害，玩家会被直接击杀并正常触发死亡事件
- 对非玩家实体直接移除，不产生掉落物和死亡动画
- 使用 `@e[type=item]` 可清除地上的掉落物
- 使用 `@e[type=!player]` 可清除所有非玩家实体
- 在没有指定目标时，执行者自身受到致命伤害
- 基岩版中 `/kill` 没有 `@s` 以外的默认目标，必须显式指定或留空（留空等于 `@s`）
- 需要 OP 等级 1
