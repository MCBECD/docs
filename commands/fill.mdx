用指定方块填充一个矩形区域。这是最常用的建筑和地图制作命令之一。

### 语法

`/fill <起点> <终点> <方块> [数据值] [模式]`

`/fill <起点> <终点> <方块> [数据值] replace [被替换方块]`

### 参数

- `<起点>` — 矩形区域的一个角坐标 `x y z`
- `<终点>` — 矩形区域的对角坐标 `x y z`
- `<方块>` — 要填充的方块 ID
- `[数据值]` — 方块数据值（已弃用）
- `[模式]` — 填充模式
- `[被替换方块]` — `replace` 模式下可指定只替换某种方块

### 填充模式

| 模式 | 说明 |
|------|------|
| `replace` | 默认模式 — 替换区域内的所有方块 |
| `destroy` | 替换方块，被替换的方块会掉落物品 |
| `hollow` | 只填充外层方块，内部填充为空气 |
| `keep` | 只填充空气位置，已有方块不受影响 |
| `outline` | 与 `hollow` 相同 — 只填充外层 |

### 示例

**填充地板**

```mcfunction
/fill ~-5 ~-1 ~-5 ~5 ~-1 ~5 stone
```

填充脚下的 11×11 石头地板。

**清除区域**

```mcfunction
/fill 0 64 0 10 70 10 air
```

清除一个 11×7×11 的区域（替换为空气），常用于快速清空空间。

**创建中空盒子**

```mcfunction
/fill ~ ~ ~ ~10 ~ ~10 glass hollow
```

创建 11×11×11 的中空玻璃盒子，内部自动填充为空气，适合制作竞技场或房间。

**保留已有方块填充**

```mcfunction
/fill ~ ~ ~ ~5 ~5 ~5 stone keep
```

在区域内只填充空气位置为石头，已有方块不受影响，适合修补缺失方块。

**精确替换方块**

```mcfunction
/fill ~ ~ ~ ~10 ~ ~10 air replace stone
```

只清除区域内的石头方块，其他方块不受影响，适合选择性拆除。

**破坏模式填充**

```mcfunction
/fill 0 60 0 20 80 20 stone destroy
```

填充大区域，原方块会掉落物品。**谨慎使用**，大型区域可能产生大量掉落物导致严重卡顿。

### 基岩版注意

- 基岩版中 `/fill` 的方块数量限制为 32768 个，超出命令会失败并提示
- 基岩版不支持 `outline` 模式，需使用 `hollow` 代替
- 基岩版中使用 `destroy` 模式时，掉落物的生成机制与 Java 版略有不同
- `[数据值]` 参数在基岩版中已完全弃用，部分旧版本仍可使用

### 相关命令

- [/clone](/commands/clone) — 复制一个区域的方块到另一个位置
- [/setblock](/commands/setblock) — 放置单个方块
- [/fill](/commands/fill) — 与 [/replaceitem](/commands/replaceitem) 配合可批量替换容器物品

>[!NOTE]
> - `/fill` 有方块数量限制（默认 32768 个方块），超出限制命令会失败
> - 使用 `destroy` 模式在大型区域中可能产生大量掉落物，导致严重卡顿
> - `hollow` / `outline` 模式适用于创建房间、竞技场等中空结构
> - 使用 `replace <方块>` 可以精确替换特定方块类型，常用于批量修改
> - 建议：操作大型区域前先备份世界存档
> - 需要 OP 等级 1
