切换玩家或自己的游戏模式，可选生存、创造、冒险、旁观与默认五种。基岩版 1.18.30 起可通过数字 `6` 访问旁观模式，1.19.50 起旁观模式脱离实验性玩法正式开放。

### 原理

游戏模式是服务端为每个玩家单独维护的状态字段，作为玩家数据的一部分随存档持久化，而不是世界的全局属性。因此同一个世界里，不同玩家可以同时处于不同的游戏模式，`/gamemode` 本质上是修改单个目标玩家的这个字段。命令执行时，服务端先把模式参数解析为 `GameMode` 枚举或对应整数，写入目标玩家的模式字段，再把变更同步给该玩家的客户端，使其立即获得新模式对应的行为。

游戏模式本身不直接实现飞行、瞬间破坏等效果，而是决定服务端授予该玩家的一组「能力」。在基岩版中，这些能力由玩家能力系统承载：`mayfly` 让玩家像创造模式一样飞行，`worldbuilder` 允许玩家即使在冒险模式也能放置与破坏方块。正因如此，游戏模式与能力可以解耦，例如通过 [`/ability`](../ability/) 单独授予或撤销某个能力，就能在不动游戏模式的前提下改变玩家的实际表现。

`/gamemode` 只修改游戏模式，不触碰物品栏、坐标、生命值、饥饿值或经验。从创造切换到生存时，飞行能力被移除，正在空中飞行的玩家会失去飞行状态并下落；从生存切换到创造时，物品栏原样保留，但玩家立即获得飞行与瞬间破坏能力。由于命令只改状态字段，重复执行即可来回切换，效果完全可逆。

模式值必须落在 `GameMode` 枚举内，任何无效值都会在解析阶段被拒绝，命令不会执行。目标参数必须是玩家类型，且至少要解析到一个在线玩家；省略时默认作用于命令执行者，若执行者不是玩家（如命令方块）则必须显式指定目标。基岩版独有的 `default`（数字 `5`）会把玩家重置为世界设置中的默认游戏模式，而不是某个固定模式。

### 语法

**枚举形式：**

`/gamemode <模式> [玩家]`

**整数形式：**

`/gamemode <整数> [玩家]`

两种形式完全等价，`<模式>` 与 `<整数>` 的对应关系见参数章节。

### 参数

- `<模式>` / `<整数>` — 目标游戏模式，必填。可填游戏模式名称、单字母缩写或整数，可选值如下表：

| 模式名 | 缩写 | 整数 | 说明 |
|--------|------|------|------|
| `survival` | `s` | `0` | 生存模式：需要采集资源，有生命值与饥饿值，不能飞行 |
| `creative` | `c` | `1` | 创造模式：无限资源，可飞行，可瞬间破坏方块，免疫绝大多数伤害 |
| `adventure` | `a` | `2` | 冒险模式：不能直接放置或破坏方块，用于自定义地图 |
| `default` | `d` | `5` | 重置为世界设置中的默认游戏模式，基岩版独有 |
| `spectator` | 无 | `6` | 旁观模式：可飞行并穿过方块观察，但不能与方块和实体交互 |

- `[玩家]` — 可选，目标选择器或玩家名，必须为玩家类型。省略时默认为命令执行者本人；若执行者不是玩家，则必须显式指定，且要解析到至少一个在线玩家。

### 示例

**把自己设为创造模式：**
<>`/gamemode creative`

省略玩家参数时默认作用于执行者本人，执行后立即获得飞行与瞬间破坏能力。

**用缩写把最近的玩家设为生存模式：**
<>`/gamemode s @p`

缩写 `s` 与 `survival` 等价，将距离执行点最近的在线玩家切换为生存模式。

**用整数把所有玩家设为冒险模式：**
<>`/gamemode 2 @a`

整数 `2` 对应冒险模式，服务器中所有在线玩家都会进入冒险模式，无法再破坏方块。

**把自己设为旁观模式：**
<>`/gamemode spectator`

进入旁观模式后可飞行并穿过方块观察世界，但无法与方块和实体交互。

**把执行者重置为世界默认模式：**
<>`/gamemode default`

`default`（或 `5`）会把玩家切回世界设置中定义的默认游戏模式。

### 基岩版注意

- 需要 OP 等级 1
- 属于作弊类命令，需在世界设置中开启「允许作弊」
- 基岩版保留整数与缩写形式（`s`、`c`、`a`、`d` 和 `0`、`1`、`2`、`5`、`6`），Java 版自 1.13 起已移除数字 ID 与缩写
- 旁观模式的整数是 `6`，Java 版则是 `3`，两版数字不通用；基岩版旁观模式没有单字母缩写
- `default`（`d` / `5`）为基岩版独有取值，Java 版改用独立的 `/defaultgamemode` 命令设置默认模式
- 旁观模式自 1.18.30 起以实验性玩法加入，1.19.50 起不再锁定于实验性玩法，此前版本不可用
- 基岩版旁观模式功能比 Java 版有限：无法使用物品或与方块、实体交互

### 常见问题

<details>
<summary>切换游戏模式会清空我的物品栏吗？</summary>

不会。`/gamemode` 只修改游戏模式字段，物品栏、坐标、生命值与经验都保持不变。从创造切到生存时，物品会原样保留，只是失去飞行与瞬间破坏等能力。

</details>

<details>
<summary>输入 /gamemode sp 为什么会报错？</summary>

基岩版旁观模式只接受 `spectator` 或数字 `6`，没有 `sp` 这个缩写。使用 `/gamemode spectator` 或 `/gamemode 6` 即可。

</details>

<details>
<summary>如何让新加入的玩家默认就是创造模式？</summary>

在世界设置中把默认游戏模式改为创造即可。基岩版没有 Java 版的 `/defaultgamemode` 命令，但可以用 `/gamemode default` 把某个在线玩家重置为世界默认模式。

</details>
