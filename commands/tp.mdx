传送实体到指定坐标或目标实体。

### 语法

`/tp <目标> <位置>`

`/tp <目标> <目的地实体>`

`/tp <位置>`

`/tp <目标> <位置> <水平旋转> <垂直旋转>`

### 参数

- `<目标>` — 被传送的实体选择器
- `<位置>` — 目标坐标 `x y z`（支持相对和局部坐标）
- `<目的地实体>` — 传送到该实体所在位置
- `<水平旋转>` — 传送后的水平朝向角度（yaw，-180~180）
- `<垂直旋转>` — 传送后的垂直朝向角度（pitch，-90~90）

### 示例

**传送到指定坐标**

```mcfunction
/tp @p 100 64 100
```

将最近玩家传送到 (100, 64, 100)。

**传送到目标实体**

```mcfunction
/tp @a @s
```

将所有玩家传送到执行者位置。

**传送到出生点**

```mcfunction
/tp 0 64 0
```

将自己传送到出生点附近。

**传送到指定玩家**

```mcfunction
/tp @p Steve
```

将最近玩家传送到 Steve 的位置。

**带旋转角度传送**

```mcfunction
/tp @s ~ ~5 ~ 90 0
```

将执行者向上传送 5 格，并朝向南方（水平旋转 90 度）。

**仅修改朝向**

```mcfunction
/tp @a ~ ~ ~ 0 90
```

将所有玩家传送到当前位置不变，但强制朝向上方。

### 坐标说明

| 类型 | 格式 | 说明 |
|------|------|------|
| 绝对坐标 | `100 64 100` | 世界中的精确位置 |
| 相对坐标 | `~ ~1 ~` | 相对于当前位置偏移 |
| 局部坐标 | `^ ^ ^1` | 相对于视线方向 |

### 基岩版注意

- 基岩版中 `/tp` 不支持 `facing` 子命令，无法指定面朝的坐标或实体
- 基岩版的旋转角度支持范围与 Java 版一致（yaw -180~180，pitch -90~90）
- 传送骑乘中的实体时，在基岩版中会解散骑乘关系

### 相关命令

- [`/execute`](../commands/execute/) — 结合 `run tp` 在更复杂的条件下传送
- [`/ride`](../commands/ride/) — 让实体骑乘或被骑乘，涉及实体位置变化
- [`/tag`](../commands/tag/) — 配合目标选择器定位特定实体后传送

>[!NOTE]
> - 实体必须处于已加载的区块中
> - 传送到实体时，默认保持原有的朝向角度
> - 可指定旋转角度来控制传送后的朝向
> - 传送到 Y 轴负数位置或超出世界高度限制会失败
> - 大量实体同时传送可能导致性能问题
> - 需要 OP 等级 1
