清除玩家物品栏中的物品。当从容器（箱子、工作台等）中用光标拿起物品时，此类物品也可以被清除。

### 语法

`/clear [玩家] [物品] [数据值] [最大数量]`

### 参数

- `[玩家]` — 玩家类型的目标选择器。指定要清除物品的玩家。必须为玩家名或玩家类型的目标选择器（如 `@p`、`@a`、`@s`）。默认为`@s`
- `[物品]` — 指定要清除的物品。必须为物品 ID（如 `diamond`、`stone`）或存在其物品形式的方块 ID。默认清除所有物品
- `[数据值]` — 指定要清除物品的数据值。如果未指定或为 `-1`，则不考虑物品的数据值
- `[最大数量]` — 指定要清除物品的最大数量。如果未指定或为 `-1`，则默认清除所有符合要求的物品

### 输出

| 条件 | 成功次数 |
|------|---------|
| 执行失败 | 0 |
| 执行成功 | 拥有指定物品的玩家数 |

### 示例

```mcfunction
/clear @p
```
清除最近玩家物品栏中的所有物品

```mcfunction
/clear @a diamond
```
清除所有玩家的钻石

```
/clear @a wool -1 0
```
获取具有羊毛的玩家的数量

> [!NOTE]
> - `最大数量` 为 `0` 时不会清除任何物品，返回符合条件的玩家数
> - `数据值` 为 `-1` 时忽略物品数据值，匹配所有变体
> - 需要 OP 等级 1
