切换玩家或自己的游戏模式，包括生存、创造、冒险和旁观模式。

### 语法

`/gamemode <模式> [玩家]`

`/gamemode <数字> [玩家]`

### 模式参数

| 模式 | 数字 | 说明 |
|------|------|------|
| `survival` | `s` / `0` | 生存模式 — 需要收集资源，有生命值 |
| `creative` | `c` / `1` | 创造模式 — 无限资源，可飞行 |
| `adventure` | `a` / `2` | 冒险模式 — 不能破坏方块，用于自定义地图 |
| `spectator` | `sp` / `6` | 旁观模式 — 可穿过方块观察，部分版本可用 |

### 参数

- `<模式>` — 游戏模式名称（`survival`、`creative`、`adventure`、`spectator`）或缩写（`s`、`c`、`a`、`sp`）或数字（`0`、`1`、`2`、`6`）
- `[玩家]` — 目标选择器（如 `@p`、`@a`、`@s`），省略时默认为执行者本人

### 示例

**将最近的玩家设为创造模式：**
```mcfunction
/gamemode creative @p
```

将距离命令执行者最近的玩家切换为创造模式，该玩家将获得无限资源和飞行能力。

**将所有玩家设为生存模式：**
```mcfunction
/gamemode survival @a
```

将服务器中所有在线玩家同时切换为生存模式，适合在游戏开始时统一设置。

**使用缩写将自己设为创造模式：**
```mcfunction
/gamemode c
```

省略玩家参数时默认作用于执行者本人，使用缩写 `c` 代替 `creative` 可以加快输入速度。

**将执行者设为旁观模式：**
```mcfunction
/gamemode spectator
```

将自己切换为旁观模式，可以自由飞行并穿过方块观察世界，但无法与方块和实体交互。

### 基岩版注意

- 需要 OP 等级 1
- 基岩版从 1.19.50 开始支持旁观模式（spectator），但功能比 Java 版有限
- 旁观模式下无法使用物品和方块交互
- 默认模式可在世界设置中更改
- 基岩版中使用数字参数切换游戏模式与 Java 版一致，但推荐使用名称以提高可读性
