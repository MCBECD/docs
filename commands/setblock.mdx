在指定位置放置单个方块。可与 [`/fill`](../commands/fill/) 配合批量放置方块。

### 语法

`/setblock <位置> <方块> [数据值] [模式]`

### 参数

- `<位置>` — 坐标 `x y z`
- `<方块>` — 方块 ID（如 `stone`、`diamond_block`、`torch`）
- `[数据值]` — 方块数据值（已弃用，新版应使用独立方块 ID）
- `[模式]` — 放置模式

### 放置模式

| 模式 | 说明 |
|------|------|
| `replace` | 默认模式 — 替换目标位置的方块（含空气） |
| `destroy` | 先破坏目标方块（掉落物品），再放置新方块 |
| `keep` | 仅在目标位置为空气时放置，否则不做任何操作 |

### 示例

**在脚下方块位置放置石头：**
```mcfunction
/setblock ~ ~ ~ stone
```
将脚下方的方块替换为石头。

**在指定坐标放置钻石块：**
```mcfunction
/setblock 100 64 100 diamond_block
```
在世界坐标 (100, 64, 100) 处放置一个钻石块。

**破坏头顶的方块并掉落物品：**
```mcfunction
/setblock ~ ~1 ~ air destroy
```
使用 `destroy` 模式将头顶方块替换为空气，原方块会掉落为物品。效果类似于挖掘。

**在脚下放置基岩：**
```mcfunction
/setblock ~ ~-1 ~ bedrock
```
将脚下方块设为不可破坏的基岩，常用于地图边界防护。

**在当前位置放置火把：**
```mcfunction
/setblock ~ ~ ~ torch
```
在执行者位置放置一个火把作为光源。如需批量放置光源，可配合 [`/fill`](../commands/fill/) 命令。

**仅在空气位置放置玻璃（不覆盖已有方块）：**
```mcfunction
/setblock ~ ~ ~ glass keep
```
使用 `keep` 模式，仅当目标位置为空气时才会放置玻璃，避免覆盖已有建筑。

### 基岩版注意

- 默认 `replace` 模式会替换任何方块（包括空气），所以总能在指定位置放置方块
- `destroy` 模式会先"挖掘"原方块，触发掉落物和方块更新
- `keep` 模式适用于保护已有建筑，避免误操作覆盖
- 放置水源/岩浆时需要注意流动方向
- 坐标 Y 值范围为 0 到 319（基岩版 1.18+），旧版为 0 到 255
- 数据值参数已弃用，新版应使用独立方块 ID（如花岗岩使用 `granite` 而非 `stone 1`）
- 需要 OP 等级 1
