将一个区域的方块复制到另一个位置。常用于复制建筑、批量建造和地图制作。

### 语法

`/clone <起点> <终点> <目标位置> [遮罩模式] [克隆模式] [方块过滤]`

### 参数

- `<起点>` `<终点>` — 源区域的两个对角坐标
- `<目标位置>` — 目标区域的西北下角坐标（最低 x、y、z）
- `[遮罩模式]` — 控制复制哪些方块
- `[克隆模式]` — 控制源区域和重叠区域的行为
- `[方块过滤]` — 当遮罩模式为 `filtered` 时，指定只复制的方块 ID

### 遮罩模式

| 模式 | 说明 |
|------|------|
| `replace` | 默认 — 复制源区域的所有方块（包括空气） |
| `masked` | 只复制非空气方块（空气不会被复制过去） |
| `filtered` | 只复制指定的方块类型 |

### 克隆模式

| 模式 | 说明 |
|------|------|
| `normal` | 默认 — 源区域和目标区域重叠时命令会失败 |
| `force` | 强制克隆，即使源区域和目标区域重叠也执行 |
| `move` | 复制后将源区域替换为空气（相当于剪切） |

### 示例

**基本克隆**

```mcfunction
/clone ~ ~ ~ ~4 ~4 ~4 100 64 0
```

将当前位置周围 5×5×5 的立方体区域复制到 (100, 64, 0)。

**剪切模式克隆**

```mcfunction
/clone ~ ~ ~ ~10 ~5 ~10 200 64 200 masked move
```

克隆建筑并移动到新位置，源区域非空气方块会被清除（剪切效果）。

**遮罩模式克隆**

```mcfunction
/clone 0 60 0 10 70 10 50 64 50 masked
```

只克隆非空气方块，目标区域的已有方块保持不变。

**过滤模式克隆**

```mcfunction
/clone 0 0 0 10 10 10 50 64 50 filtered normal diamond_block
```

只克隆区域内的钻石块，其他方块类型不会被复制。

**强制重叠克隆**

```mcfunction
/clone ~ ~ ~ ~5 ~5 ~5 ~10 ~ ~ force
```

即使源区域与目标区域存在重叠，也强制执行克隆操作。

### 基岩版注意

- 基岩版中 `/clone` 不支持 `filtered` 遮罩模式的方块过滤参数（部分版本受限）
- 基岩版的方块数量限制为 32768 个，与 Java 版一致
- 基岩版中克隆包含 NBT 数据的方块（如命令方块）时，部分数据可能丢失
- `move` 模式在基岩版中表现稳定，不会出现方块闪烁问题

### 相关命令

- [/fill](/commands/fill) — 用方块填充矩形区域，常与 `/clone` 配合使用
- [/setblock](/commands/setblock) — 放置单个方块
- [/structure](/commands/structure) — 保存和加载结构文件（更灵活的替代方案）

> [!NOTE]
> - 可克隆的最大方块数量有限制（32768），超出会失败
> - 目标位置是区域的**西北下角**（最小 x、y、z 坐标）
> - `move` 模式相当于复制 + 清除源区域，比单独执行两个命令更高效
> - `masked` 模式下空气不会被复制，目标区域的原有方块保持不变
> - 区域的源和目标重叠时需要使用 `force` 模式
> - 克隆会保留方块的状态（如箱子内容物、告示牌文字、命令方块命令等）
> - 建议：克隆大型结构前先备份世界存档
> - 需要 OP 等级 1
