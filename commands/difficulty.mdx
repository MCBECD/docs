设置游戏难度等级。

### 语法

`/difficulty <等级>`

### 难度等级

| 等级 | 数字 | 说明 |
|------|------|------|
| `peaceful` | `0` | 和平 — 无怪物生成，生命值自动恢复 |
| `easy` | `1` | 简单 — 怪物伤害较低 |
| `normal` | `2` | 普通 — 标准难度 |
| `hard` | `3` | 困难 — 怪物伤害高，僵尸可破门 |

### 示例

**设为和平模式：**
```mcfunction
/difficulty peaceful
```

将难度设为和平，不再生成新的敌对生物，已有怪物不会消失。

**设为普通难度：**
```mcfunction
/difficulty 2
```

使用数字参数将难度设为普通。数字和名称两种写法均可。

**设为困难难度：**
```mcfunction
/difficulty hard
```

困难模式下怪物伤害更高，僵尸可以破门，是 survival 挑战的首选难度。难度设置也可在 [`/gamerule`](../commands/gamerule/) 中配合其他规则调整游戏体验。

### 基岩版注意

- 难度影响怪物生成、伤害值和行为
- 困难难度下僵尸可以破门
- 和平模式下已有怪物不会消失，但不会新生成
- 难度可在世界设置中永久更改
- 基岩版不支持 `difficulty` 作为 [`/gamerule`](../commands/gamerule/) 的子命令
- 需要 OP 等级 1
