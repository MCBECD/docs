`/help` 用于查看单个命令的用法说明，或分页列出当前可用的全部命令。它不要求开启「允许作弊」，任何玩家都能在聊天栏直接执行，别名 `/?` 自携带版 Alpha 0.16.0 起与之一同加入。

### 原理

`/help` 是一个纯查询命令，执行它不会改动世界、实体、物品栏或计分板中的任何状态。它真正读取的对象是游戏内置的命令注册表（command registry）：引擎在启动时把所有可用命令的名称、语法说明与所需权限登记成一份只读清单，`/help` 要做的就是从这张清单里取出对应条目，再把它格式化成聊天文本输出。正因为整个过程只涉及一次查表与一次文本输出，它才不需要开启作弊，也没有任何副作用。

带命令名执行时，`/help` 把参数当作一个枚举值去匹配命令注册表。基岩版的 `<命令>` 参数类型是 `CommandName` 枚举，只接受一个完整、已注册的命令名，例如 `give`、`execute`、`scoreboard`；如果你输入了不存在的名字，参数在解析阶段就直接失败，命令不会产生任何输出。这也是它与 Java 版最关键的分野：Java 版的 `<command>` 是贪婪短语（greedy phrase），允许一直写到子命令层级（如 `help scoreboard objectives add`），而基岩版只能填单个命令名，无法用一条 `/help` 查看子命令的用法。

不带参数或带页码执行时，`/help` 走的是列表模式。引擎先把命令注册表中的条目按执行者可用权限过滤一遍——Minecraft Wiki 记载，执行者因权限等原因无法使用的命令不会出现在列表中；随后把剩余条目切分成若干页，一次只显示一页。`[页码]` 是一个 32 位整数，小于 1 的数值会被钳制为第 1 页，大于总页数的数值会被钳制为最后一页，省略时默认显示第 1 页，因此直接输入 `/help` 与 `/help 1` 等价。

`?` 是基岩版命令注册表中的一个独立条目，功能与 `help` 完全一致，`/?` 因此成为 `/help` 的别名。这意味着 `help` 和 `?` 本身也出现在自己的列表里，你可以用 `/help help` 或 `/help ?` 反过来查询这条命令的用法。由于 `/help` 只依赖本地注册表、不访问网络或存档文件，它的输出在任何维度、任何时间点都保持一致。

### 语法

`/help <命令>`

查看指定命令的用法与全部语法。

`/help [页码]`

分页列出当前可用的命令。省略页码时显示第 1 页。

### 参数

- `<命令>` — 枚举类型（`CommandName`）。要查询用法的命令名，必须是已注册的有效命令名（如 `give`、`execute`、`scoreboard`）；只能填单个命令名，不能附带子命令或参数，填写不存在的名字会解析失败。
- `[页码]` — 整数类型（`int`）。命令列表的页码，从 1 开始计数。省略时默认为第 1 页；小于 1 按第 1 页处理，大于总页数按最后一页处理。

### 示例

**查看命令列表第一页：**

```mcfunction
/help
```

省略页码时默认显示第 1 页，聊天栏会列出你当前可用的前几条命令。要翻页时继续执行 `/help 2`、`/help 3`。

**查看 /give 的用法：**

```mcfunction
/help give
```

聊天栏返回 `/give` 的语法模板与参数说明，方便你快速回忆物品、数量、组件等参数的先后顺序。

**跳到命令列表的第三页：**

```mcfunction
/help 3
```

直接显示第 3 页命令列表。若列表总页数不足 3 页，命令会自动回退到最后一页，而不会报错。

**用别名查看 /execute 的用法：**

```mcfunction
/? execute
```

`/?` 是 `/help` 的别名，效果与 `/help execute` 完全相同，聊天栏会返回 `/execute` 的用法说明。

### 基岩版注意

- 无需 OP 等级（权限等级 0），也无需开启「允许作弊」，任何玩家都能在聊天栏执行。
- 与 Java 版的主要差异：基岩版的 `<命令>` 是 `CommandName` 枚举，只能填单个命令名，无法像 Java 版那样用贪婪短语查子命令（如 `help scoreboard add`）；基岩版的命令列表仍分页显示，而 Java 版自 1.13 起已取消分页。
- 别名 `/?` 仅存在于基岩版；Java 版曾在 1.3.1 加入该别名，但已于 1.13 移除。
- `/help` 是只读命令，不会修改世界、实体或玩家数据，输出直接显示在聊天栏，适合作为快速查语法的方式。
- 版本兼容：自携带版 Alpha 0.16.0 起一直可用，语法在基岩版各版本间基本稳定，无近期破坏性变更。

### 常见问题

<details>
<summary>为什么 /help scoreboard objectives add 会报错？</summary>

基岩版的 `<命令>` 参数是枚举，只能接受一个完整命令名。要查看 `/scoreboard` 的用法请输入 `/help scoreboard`；子命令的详细用法请直接查阅 [`/scoreboard`](../scoreboard/) 文档。

</details>

<details>
<summary>为什么我在列表里看不到某个命令？</summary>

`/help` 会过滤掉执行者无权使用的命令。某些命令还依赖实验性玩法或附加包，未启用时也不会出现在列表里。具体的过滤规则因版本而异，建议以游戏内实测为准（待验证）。

</details>

<details>
<summary>/help 和 /? 有什么区别？</summary>

没有区别。`?` 在基岩版命令注册表中是 `help` 的等价条目，`/?` 只是它的别名写法，两者输出的内容完全一致。

</details>
