基岩版最强大的命令。改变命令的执行上下文（执行者、位置、角度、维度），并支持条件判断。几乎所有复杂的命令系统都依赖于 `/execute`。

### 子命令一览

#### 执行上下文

| 子命令 | 说明 |
|--------|------|
| `as <实体>` | 以该实体的身份执行后续命令（改变执行者） |
| `at <实体>` | 在该实体的位置执行（改变坐标） |
| `positioned <x> <y> <z>` | 在指定坐标执行 |
| `positioned ~ ~ ~` | 重置为世界原点执行 |
| `rotated <yaw> <pitch>` | 设定视角角度执行 |
| `rotated as <实体>` | 使用实体的视角角度执行 |
| `in <维度>` | 在指定维度执行 |

#### 条件判断

| 子命令 | 说明 |
|--------|------|
| `if <条件>` | 条件为真时执行 |
| `unless <条件>` | 条件为假时执行（与 if 相反） |

支持的判断条件：

| 条件 | 说明 |
|------|------|
| `block <x> <y> <z> <方块>` | 指定位置是指定方块 |
| `block <x> <y> <z> <方块> [数据值]` | 指定位置是指定方块（含数据值） |
| `blocks <起点> <终点> <目标> <模式>` | 区域方块匹配 |
| `entity <实体>` | 实体存在 |
| `score <玩家> <目标> <运算> <值>` | 分数比较 |
| `score <玩家> <目标> <运算> <源玩家> <源目标>` | 两个分数比较 |

运算符：`=`, `<`, `>`, `<=`, `>=`

| 条件 | 说明 |
|------|------|
| `detect <x> <y> <z> <方块> [数据值]` | 检测指定位置的方块（if/unless） |

#### 其他

| 子命令 | 说明 |
|--------|------|
| `facing <x> <y> <z>` | 朝向指定坐标执行 |
| `facing entity <实体> [eyes/feet]` | 朝向实体执行 |
| `anchored eyes` | 以实体眼睛高度为基准 |
| `anchored feet` | 以实体脚底为基准 |
| `run <命令>` | 执行最终命令（必须放在最后） |

### 语法

`/execute <子命令>... run <命令>`

多个子命令可以链式组合，最后以 `run` 结束并执行目标命令。

### 参数

由于 `/execute` 是子命令驱动的命令，各子命令的参数不同。以下列出所有子命令中出现的公共参数。

- `<实体>` — 目标选择器（如 `@a`、`@e`、`@p`、`@s`）
- `<x> <y> <z>` — 世界坐标（整数，支持 `~` 相对坐标）
- `<维度>` — 维度 ID（见下方维度 ID 表）
- `<方块>` — 方块 ID（如 `stone`、`diamond_block`）
- `[数据值]` — 方块数据值（整数，0-15）
- `<起点> <终点> <目标>` — 用于 `blocks` 条件的三组坐标
- `<模式>` — 方块匹配模式（`all` 或 `masked`）
- `<玩家>` — 目标玩家选择器
- `<目标>` — 计分板目标名称（字符串）
- `<运算>` — 比较运算符（`=`、`<`、`>`、`<=`、`>=`）
- `<值>` — 整数值
- `<源玩家> <源目标>` — 用于分数比较的源玩家和源计分板目标
- `<yaw> <pitch>` — 水平旋转角和垂直旋转角（浮点数，单位为度）
- `<命令>` — 要执行的最终命令字符串

### 维度 ID

| 维度 | ID |
|------|-----|
| 主世界 | `overworld` |
| 下界 | `nether` |
| 末地 | `the_end` |

### 示例

**在每个玩家脚下放置钻石块：**

```mcfunction
/execute as @a at @s run setblock ~ ~-1 ~ diamond_block
```

遍历所有玩家，在各自脚下位置放置钻石块。`as` 切换执行者为每位玩家，`at` 将执行坐标移动到玩家位置。

**在最近玩家头顶召唤闪电：**

```mcfunction
/execute at @p run summon lightning_bolt ~ ~2 ~
```

在距离命令执行点最近的玩家头顶两格处召唤一道闪电。仅改变坐标，不改变执行者身份。

**杀死站在沙子上的僵尸：**

```mcfunction
/execute as @e[type=zombie] at @s if block ~ ~-1 ~ sand run kill @s
```

遍历所有僵尸，仅当脚下方块为沙子时才将其杀死。结合了 `as`、`at`、`if block` 三个子命令实现条件过滤。

**给站在草方块上的玩家发放钻石：**

```mcfunction
/execute as @a at @s if block ~ ~-1 ~ grass run give @s diamond 1
```

仅给脚底为草方块的玩家发放一颗钻石。未站在草方块上的玩家不会执行 [`/give`](../commands/give/) 命令。

**根据分数显示达标提示：**

```mcfunction
/execute as @a if score @s money >= 100 run title @a title "达标！"
```

检查每位玩家的 `money` 计分板分数，达到 100 及以上的玩家会看到标题文字「达标！」。需要先通过 [`/scoreboard`](../commands/scoreboard/) 创建 `money` 目标。

**检测附近安全后显示消息：**

```mcfunction
/execute unless entity @e[type=zombie,r=10] run title @p actionbar "附近安全"
```

当半径 10 格内不存在僵尸时，向最近玩家显示动作栏消息。`unless` 表示条件不成立时才执行。

**朝向最近玩家发射火焰粒子：**

```mcfunction
/execute at @p facing entity @p eyes run particle minecraft:basic_flame_particle ~ ~ ~1
```

在最近玩家位置，朝该玩家视线方向偏移一格处发射火焰粒子。`facing entity` 使执行方向对准玩家眼睛位置。

**在世界原点放置命令方块：**

```mcfunction
/execute positioned 0 64 0 run setblock ~ ~ ~ command_block
```

在坐标（0, 64, 0）处放置一个命令方块。`positioned` 将执行坐标设置为指定绝对坐标，不受原执行者位置影响。

**在下界中搜索要塞：**

```mcfunction
/execute in nether run locate fortress
```

切换到下界维度后执行 [`/locate`](../commands/locate/) 搜索下界要塞。`in` 子命令改变命令执行的维度上下文。

**在末地召唤末影龙：**

```mcfunction
/execute in the_end run summon ender_dragon 0 64 0
```

切换到末地维度，在坐标（0, 64, 0）处召唤末影龙。使用 [`/summon`](../commands/summon/) 配合维度切换实现跨维度操作。

**给所有存活玩家累加生存时间分数：**

<CmdRepeat>/execute as @a if entity @s run scoreboard players add @s survival_time 1</CmdRepeat>

在循环命令方块中每游戏刻为所有在线玩家累加 `survival_time` 分数。`if entity @s` 确保仅存活的实体被计入，配合 [`/scoreboard`](../commands/scoreboard/) 使用。

**检测并替换岩浆方块：**

```mcfunction
/execute at @p if block ~ ~-1 ~ lava run setblock ~ ~-1 ~ obsidian
```

检测最近玩家脚下是否为岩浆，如果是则替换为黑曜石。使用 [`/setblock`](../commands/setblock/) 实现条件方块替换。

### 基岩版注意

- 需要 OP 等级 2
- `/execute` 子命令链的顺序很重要：`as` 改变执行者，`at` 改变位置，`if/unless` 进行判断
- `run` 必须放在命令链最后，表示执行最终命令
- 基岩版的 `/execute` 功能相比 Java 版有一些限制，如不支持 `store` 子命令
- 条件判断失败时，整个命令链不会执行
- `if score` 支持与具体数值比较，也支持两个玩家分数之间的比较
- 配合 [`/tp`](../commands/tp/) 可实现更灵活的位置操作
- 常与 [`/tag`](../commands/tag/) 结合使用，通过实体标签进行条件筛选

### 相关命令

- [`/tp`](../commands/tp/) — 传送实体到指定位置
- [`/scoreboard`](../commands/scoreboard/) — 管理计分板，常与 `/execute if score` 配合
- [`/tag`](../commands/tag/) — 管理实体标签，用于条件筛选
- [`/setblock`](../commands/setblock/) — 在指定位置放置方块
- [`/summon`](../commands/summon/) — 生成实体
