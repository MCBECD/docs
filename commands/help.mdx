获取单个或多个命令的帮助信息

### 语法
`/help <命令>`
获取指定命令的帮助信息。必须为单个词或者双引号（"）括起的字符串。
`/help [页码]`
列出所有可用命令。未指定或小于1的会被视为1，大于总页数会被默认为展示最后一页。

### 示例

```mcfunction
/help clone
```
获取`clone`命令的帮助信息。

```mcfunction
/help
```
显示命令列表（第一页）

> [!NOTE]
> - `?` 命令是 `help` 命令的别名
