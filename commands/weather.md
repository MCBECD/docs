设置游戏天气为晴天、下雨或雷暴，并可指定持续时间。

### 语法

`/weather <类型> [持续时间]`

### 天气类型

| 类型 | 说明 |
|------|------|
| `clear` | 晴天 |
| `rain` | 下雨 |
| `thunder` | 雷暴 |

### 参数

- `<类型>` — 天气类型，可选值：`clear`（晴天）、`rain`（下雨）、`thunder`（雷暴）
- `[持续时间]` — 天气持续时间（游戏刻，1 秒 = 20 刻），默认随机（下雨 3000-6000 刻，雷暴 3000-6000 刻，最大 1000000 刻）

### 示例

**设置为晴天：**
```mcfunction
/weather clear
```

立即清除当前天气，切换为晴天，持续时间使用默认值。

**设置 5 分钟的下雨：**
```mcfunction
/weather rain 6000
```

将天气设为下雨并持续 6000 刻（300 秒 = 5 分钟）。适合用于需要持续雨天效果的地图或场景。

**设置为雷暴天气：**
```mcfunction
/weather thunder
```

将天气设为雷暴，包含闪电效果，持续时间使用默认值。雷暴天气下会随机产生闪电，可能引燃方块。

**永久晴天：**
```mcfunction
/weather clear 1000000
```

将晴天持续时间设为最大值（1000000 刻），在实际游戏中相当于永久晴天，常用于建筑或展示地图。

### 基岩版注意

- 需要 OP 等级 1
- 持续时间单位为游戏刻（tick），不是秒。1 秒 = 20 刻
- 晴天也会自然结束，使用大数值可近似实现永久晴天
- 基岩版的天气行为与 Java 版基本一致，但雷暴天气中闪电的生成频率可能略有不同
