在玩家屏幕中央显示主标题、副标题，以及在快捷栏上方显示操作栏消息。基岩版 `/title` 与 Java 版的核心子命令一致，但文本格式使用原始 JSON（rawtext）而非 Java 版的 JSON 文本组件；该命令自携带版 1.0.5（末地更新）起加入。

### 原理

`/title` 由服务端执行，但文字最终渲染在目标玩家各自的客户端屏幕上。命令执行后，服务端不会在世界里生成任何方块或实体，而是更新该玩家专属的标题状态，并向其客户端发送一条 SetTitle 数据包。这个包里携带了文字类型（主标题、副标题或操作栏）、文本内容，以及淡入、停留、淡出三段计时数值。客户端收到包后，由 HUD（平视显示器）界面按照「淡入 → 停留 → 淡出」的时间轴把文字绘制出来。因为标题只存在于运行内存中而不写入存档，玩家断开连接或重新登录后，之前显示的标题会自动消失，不会残留到下次会话。

`/title` 维护三块相互独立的文字槽：主标题（`title`）、副标题（`subtitle`）和操作栏（`actionbar`）。设置其中一块不会清空另外两块：主标题与副标题共享屏幕中央的显示区域，副标题作为较小的文字渲染在主标题正下方；操作栏则独立显示在快捷栏正上方，一旦显示会持续停留，直到被新的操作栏消息覆盖。淡入、停留、淡出这三段时长是「每名玩家一份」的持久状态，`times` 的作用只是写入这份状态，而随后执行的 `title` 或 `subtitle` 在渲染时才去读取它。因此必须先执行 `times` 再执行 `title`：如果顺序颠倒，标题会沿用上一次存储的旧时长，而不是你刚设置的新值。

三段时长都以「游戏刻」为单位，每秒固定 20 游戏刻，默认值分别为淡入 10 刻（0.5 秒）、停留 70 刻（3.5 秒）、淡出 20 刻（1 秒），即一条标题默认约 5 秒走完整个生命周期。文字参数属于 message 类型，既可以填纯文本，也可以填原始 JSON（rawtext）来叠加颜色、粗体等样式；纯文本中还能直接内嵌 § 格式化代码。`clear` 只负责立即撤下屏幕中央正在显示的主标题与副标题，不会改动 `times` 已存储的时长；`reset` 则把副标题清空，并把三段时长恢复为默认值。

### 语法

`/title <玩家> clear`

`/title <玩家> reset`

`/title <玩家> title <标题文字>`

`/title <玩家> subtitle <副标题文字>`

`/title <玩家> actionbar <操作栏文字>`

`/title <玩家> times <淡入> <停留> <淡出>`

### 参数

- `<玩家>` — 选择器（玩家类型）。要显示标题的目标，只能是玩家名或玩家类型选择器（如 `@p`、`@a`、`@s`、`@r`），不接受非玩家实体。
- `title` / `subtitle` / `actionbar` — 位置枚举。决定文字显示在屏幕的哪个位置：`title` 是屏幕中央的大号主标题，`subtitle` 是主标题正下方的小号副标题，`actionbar` 是快捷栏上方的操作栏消息。三者各占一块独立文字槽，互不影响。
- `<标题文字>` — message 类型字符串。主标题的内容，支持纯文本、§ 格式化代码以及原始 JSON（rawtext）。
- `<副标题文字>` — message 类型字符串。副标题的内容，显示在主标题正下方，字号较小，格式支持与主标题相同。
- `<操作栏文字>` — message 类型字符串。操作栏消息的内容，显示在快捷栏（物品栏）上方，格式支持同上。
- `clear` — 立即清空屏幕中央正在显示的主标题与副标题。它只撤下已显示的文字，不会修改 `times` 已存储的时长。
- `reset` — 把副标题清空，并把淡入、停留、淡出三段时长恢复为默认值（10/70/20 刻）。
- `<淡入>` — 整数（游戏刻）。标题从透明渐变到完全显示所经历的时长，默认 10。
- `<停留>` — 整数（游戏刻）。标题完全显示后保持不动的时长，默认 70。
- `<淡出>` — 整数（游戏刻）。标题从完全显示渐变到透明所经历的时长，默认 20。

### 文字格式

标题、副标题和操作栏的文字参数都接受两种写法：纯文本（可直接内嵌 § 格式化代码）和原始 JSON。原始 JSON 必须写成 `{"rawtext":[...]}` 结构，数组中的每个元素是一个对象，常用键有 `text`（字面文本）、`translate`（本地化键名）和 `score`（引用计分板分数）。JSON 整体需要写成单个参数，如果内部包含空格，建议用双引号把整个 JSON 包裹起来。

| 代码 | 效果 |
|------|------|
| `§0` | 黑色 |
| `§1` | 深蓝色 |
| `§9` | 蓝色 |
| `§a` | 绿色 |
| `§b` | 青色 |
| `§c` | 红色 |
| `§d` | 浅紫色 |
| `§e` | 黄色 |
| `§f` | 白色 |
| `§6` | 金色 |
| `§l` | 粗体 |
| `§o` | 斜体 |
| `§n` | 下划线 |
| `§k` | 乱码（随机闪烁字符） |
| `§r` | 重置为默认样式 |

### 示例

**显示简单主标题：**

<>`/title @p title 欢迎来到服务器`

在最近玩家的屏幕中央显示主标题「欢迎来到服务器」。淡入、停留、淡出均使用默认时长，即 10/70/20 刻。

**显示带副标题的主标题：**

<>`/title @p title Boss 已被击败`
<>`/title @p subtitle 恭喜全体玩家`

先显示主标题「Boss 已被击败」，再在其正下方以小号文字显示副标题「恭喜全体玩家」。副标题依附主标题渲染，需先有主标题才能看到它。

**在操作栏显示消息：**

<>`/title @a actionbar §a§l你发现了隐藏区域`

在所有玩家的快捷栏上方显示绿色粗体的操作栏消息「你发现了隐藏区域」。操作栏与主标题互不影响，会一直停留，直到被下一条 actionbar 覆盖。

**自定义淡入淡出并显示金色标题：**

<>`/title @a times 30 100 20`
<>`/title @a title §6第 1 轮开始`

先为所有玩家设定淡入 30 刻（1.5 秒）、停留 100 刻（5 秒）、淡出 20 刻（1 秒）的时长，再显示金色主标题「第 1 轮开始」。times 必须写在 title 之前，否则标题会沿用上一次存储的时长。

**用原始 JSON 组合样式：**

<>`/title @p title {"rawtext":[{"text":"§c§l警报"},{"text":"：请迅速撤离"}]}`

用原始 JSON 把红色粗体的「警报」和默认颜色的「：请迅速撤离」拼成一条主标题。多个 text 对象按顺序拼接，适合在同一条标题里混用不同颜色与样式。

**提前清除标题：**

<>`/title @a clear`

立即移除所有玩家屏幕中央正在显示的标题与副标题，适合在过场动画结束或玩家死亡时提前打断尚未播完的标题。此命令不影响操作栏，也不会重置 times 时长。

### 基岩版注意

- 需要 OP 等级 1，且世界必须开启作弊。
- 与 Java 版的差异：文本格式不同。基岩版使用原始 JSON（`{"rawtext":[...]}`），Java 版使用 JSON 文本组件（`{"text":"..."}`）；两版的核心子命令与默认时长（10/70/20 刻）一致。
- `times` 必须在 `title` 或 `subtitle` 之前执行，因为它写入的是「每名玩家一份」的持久时长状态，标题在渲染时才读取。
- 副标题依附主标题显示：只设置 subtitle 而不设置 title 时，屏幕通常不会单独出现副标题文字。
- 操作栏（actionbar）与主标题互不影响，显示后会一直停留，直到被新的操作栏消息覆盖。
- 版本兼容：`/title` 自携带版 1.0.5（末地更新）起加入，核心语法在后续版本中保持稳定。
- 1 秒 = 20 游戏刻。

### 常见问题

<details>
<summary>标题一闪而过，几乎看不到？</summary>

检查是否先执行了 times。若先显示 title 再执行 times，标题会沿用上一次存储的旧时长（默认 10/70/20 刻），导致淡入淡出很快。应把 times 放在 title 之前，或用 reset 恢复默认时长。

</details>

<details>
<summary>副标题为什么不显示？</summary>

副标题需要依附主标题才能显示。单独执行 subtitle 只会把文字存储起来，屏幕上通常不会单独出现；请先执行 title 再执行 subtitle，或把两者写进同一条命令链。

</details>

<details>
<summary>操作栏消息能清除吗？</summary>

`clear` 只清除屏幕中央的标题与副标题，不影响操作栏。操作栏没有独立的清除子命令，通常用一条新的 actionbar 消息把它覆盖。

</details>

<details>
<summary>为什么用 @e 选择器会报错？</summary>

因为 `<玩家>` 参数只接受玩家类型，`@e` 会同时选中非玩家实体而导致目标无效。请改用 `@a`、`@p`、`@s`、`@r` 等玩家选择器，或写成 `@e[type=player]`。

</details>
