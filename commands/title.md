在玩家屏幕上显示文字，包括主标题、副标题和操作栏消息。

### 语法

`/title <玩家> clear`

`/title <玩家> reset`

`/title <玩家> title <标题文字>`

`/title <玩家> subtitle <副标题文字>`

`/title <玩家> actionbar <操作栏文字>`

`/title <玩家> times <淡入> <停留> <淡出>`

### 参数

- `<玩家>` — 目标玩家
- `<标题文字>` — 主标题文字（支持原始 JSON 文本）
- `<副标题文字>` — 主标题下方的副标题文字
- `<操作栏文字>` — 显示在操作栏上的文字（快捷栏上方）
- `<淡入>` — 淡入持续时间，以刻为单位（默认：10）
- `<停留>` — 标题在屏幕上停留的持续时间，以刻为单位（默认：70）
- `<淡出>` — 淡出持续时间，以刻为单位（默认：20）
- `clear` — 立即移除当前标题
- `reset` — 将标题时间重置为默认值

### 示例

**显示简单标题：**
```mcfunction
/title @p title 欢迎！
```

在所有最近玩家的屏幕中央显示"欢迎！"标题文字。

**显示带副标题的标题：**
```mcfunction
/title @p title Boss被击败了！
/title @p subtitle 恭喜！
```

先设置主标题"Boss被击败了！"，再设置副标题"恭喜！"。副标题显示在主标题下方，字号较小。

**在操作栏上显示消息：**
```mcfunction
/title @p actionbar §a§l你发现了秘密！
```

在快捷栏上方显示绿色粗体的操作栏消息。操作栏文字会一直保留直到被清除或覆盖。

**自定义淡入淡出时间：**
```mcfunction
/title @p times 30 100 20
/title @p title §6第 1 轮
```

先设置 1.5 秒淡入、5 秒停留、1 秒淡出的时间，再显示金色标题"第 1 轮"。注意时间必须在标题之前设置。

**提前清除标题：**
```mcfunction
/title @p clear
```

立即移除屏幕上显示的标题，适用于中断正在播放的标题动画。如需播放声音配合标题，可使用 [`/playsound`](../commands/playsound/) 命令。配合 [`/execute`](../commands/execute/) 可实现条件化的标题触发，例如仅当玩家进入某区域时显示提示。

### 文字格式

标题支持带格式化代码和组件的原始 JSON 文本：

```mcfunction
/title @p title {"rawtext":[{"text":"§c§l警报！"}]}
```

### 常用格式化代码

| 代码 | 效果 |
|------|------|
| `§0` | 黑色 |
| `§c` | 红色 |
| `§a` | 绿色 |
| `§b` | 青色 |
| `§e` | 黄色 |
| `§6` | 金色 |
| `§l` | 粗体 |
| `§o` | 斜体 |
| `§k` | 乱码 |
| `§n` | 下划线 |

### 基岩版注意

- 标题时间必须在显示标题之前设置才能生效
- 默认时间：淡入 10 刻，停留 70 刻，淡出 20 刻
- 1 秒 = 20 刻
- 操作栏文字显示在快捷栏上方，会一直保留直到被清除
- 推荐使用 JSON rawtext 发送格式化文字
- 基岩版不支持 `title` 的 `times` 中的无限持续时间
- 需要 OP 等级 1
