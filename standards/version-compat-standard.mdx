## 版本兼容性标准

Minecraft 基岩版的命令系统在不同版本间存在大量差异。MCBECD 文档以**最新正式版**为默认基准，同时记录历史版本的差异。本文档定义版本信息的记录规范。

---

### 一、版本标记规则

#### 1.1 默认基准版本

MCBECD 文档的默认基准版本为**最新的正式发布版**。文档中的命令语法、参数和行为描述以最新版为准。

#### 1.2 版本号格式

在文档中引用版本号时，使用以下格式：

- 完整版本号：`1.20.50`、`1.21.30`
- 小版本范围：`1.20.50+`、`1.21.0 及以上`

不使用的格式：
- `v1.20.50`（不加 `v` 前缀）
- `1.20.5`（不省略末尾的零）
- `Beta 1.20.50.20`（不引用测试版，除非特别说明）

#### 1.3 版本标注方式

当描述版本差异时，使用以下方式标注：

**行内标注**（适用于简短说明）：

```
基岩版 1.20.50+ 已弃用旧版数据值语法。
```

**版本分段**（适用于大段差异描述）：

```
**新版语法（1.20.50+）：**

`/give <玩家> <物品> [数量] [组件]`

**旧版语法（1.20.50 以下）：**

`/give <玩家> <物品> [数量] [数据值] [组件]`
```

**提示框标注**（适用于重要提醒）：

```mdx
> [!WARNING] 版本差异
> 此语法仅在 1.20.50 及以上版本中可用。旧版请使用数据值参数。
```

### 二、废弃语法处理

#### 2.1 废弃标注

当某个语法或参数在最新版中被废弃时：

1. 在文档中**保留**废弃语法的说明（因为仍有玩家使用旧版）
2. 明确标注为「已弃用」
3. 说明替代方案
4. 标注废弃的版本号

正确示例：

```
- `[数据值]` — 旧版物品变体数据值（**已弃用**，1.20.50+ 应使用独立物品 ID）
```

#### 2.2 不记录完全移除的命令

如果某个命令在最新版中已被完全移除（如 `/data`），在「基岩版注意」中简要说明：

```
- 基岩版不支持 /data 命令（无法直接修改实体或方块数据）
```

### 三、网易版差异记录

#### 3.1 记录范围

当命令在网易版和国际版之间存在差异时，必须在「基岩版注意」章节中记录。

#### 3.2 标签

对存在网易版差异的文档添加 `"网易差异"` 标签。

#### 3.3 记录格式

```
- 网易版与国际版在命令语法上存在细微差异，本文档基于国际版编写
- 网易版中 `[参数]` 的可选值有所不同，请以网易版实际测试为准
```

#### 3.4 不逐条列出网易版差异

如果差异较小或难以穷举，使用概括性描述，不逐条列出。

---

### 四、版本迁移指南

#### 4.1 文档中的迁移说明

当某个重要语法变化影响大量命令时，可以在对应文档中添加迁移说明。

#### 4.2 迁移说明格式

```
**迁移指南（1.20.50+）：**

如果你从旧版迁移，主要变化如下：
- 花岗岩从 `stone 1` 变为 `granite`
- 闪长岩从 `stone 3` 变为 `diorite`
- 安山岩从 `stone 5` 变为 `andesite`
- 所有物品数据值已弃用，改用独立物品 ID
```

---

### 五、OP 等级记录

#### 5.1 记录规则

每篇命令文档的「基岩版注意」章节必须包含 OP 等级要求。

#### 5.2 记录格式

```
- 需要 OP 等级 1
- 需要 OP 等级 2
```

#### 5.3 OP 等级参考

| 等级 | 权限 | 典型命令 |
|------|------|----------|
| 0 | 普通玩家 | 聊天命令 |
| 1 | 基础命令 | 大部分命令（give、kill、tp 等） |
| 2 | 高级命令 | execute |
