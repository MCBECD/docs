## `/enchant` — 附魔

为玩家选中的物品添加附魔。默认对主手栏物品生效，也可指定副手栏。

### 语法

`/enchant <player: target> <enchantmentName: Enchant> <level: int> [enchantItemWith: EnchantItemOption]`

### 参数

- `player: target` — 目标玩家，必须持有可附魔的物品。
- `enchantmentName: Enchant` — 附魔标识符（如 `sharpness`、`protection`、`efficiency`）。
- `level: int` — 附魔等级，从 1 到该附魔的最大等级。
- `enchantItemWith: EnchantItemOption`（可选）— 指定要附魔的物品栏位，可选值为 `mainhand`（主手）或 `offhand`（副手）。默认为 `mainhand`。

### 示例

**为最近玩家的主手物品附魔锋利 V：**

```
/enchant @p sharpness 5
```

**为自己持有的物品附魔效率 V：**

```
/enchant @s efficiency 5
```

**为所有玩家的主手物品附魔精准采集：**

```
/enchant @a silk_touch 1
```

**为最近玩家的副手物品附魔经验修补：**

```
/enchant @p mending 1 offhand
```

**为所有玩家的主手物品附魔耐久 III：**

```
/enchant @a unbreaking 3 mainhand
```

### 基岩版注意

- 需要 OP 等级 1
- 玩家必须持有支持该附魔的物品，否则命令会失败
- 不兼容的附魔（如锋利与亡灵杀手）不能同时存在于同一物品上
- 等级参数为必填项，即使附魔 I 级也必须写 `1`
- `enchantItemWith` 参数为基岩版特有，用于指定对主手还是副手物品附魔，默认为主手
- 可以通过命令应用超过正常上限的附魔等级（如锋利 100），但实际效果有上限
- `/enchant` 只能对玩家手持的物品生效，不能对掉落物或容器中的物品附魔
