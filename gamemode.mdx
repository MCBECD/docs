## `/gamemode` — 游戏模式

设置玩家的游戏模式。可切换为生存、创造、冒险或旁观模式。

### 语法

`/gamemode <gameMode: GameMode> [player: target]`

### 参数

- `gameMode: GameMode` — 要设置的游戏模式，必须为以下值之一：
- `player: target`（可选）— 目标玩家。若未指定，默认为命令执行者自身。

### 游戏模式

| 模式 | 缩写 | 数字 | 说明 |
|------|------|------|------|
| `survival` | `s` | `0` | 生存模式 — 需要收集资源，有生命值和饥饿值 |
| `creative` | `c` | `1` | 创造模式 — 无限资源，可飞行，可 instant break 方块 |
| `adventure` | `a` | `2` | 冒险模式 — 只能通过交互来破坏方块，适用于自定义地图 |
| `spectator` | `sp` | `6` | 旁观模式 — 可自由飞行穿墙观察，不能与世界交互 |

### 示例

**将执行者设为创造模式（三种等价写法）：**

```
/gamemode creative
/gamemode c
/gamemode 1
```

**将所有玩家设为生存模式：**

```
/gamemode survival @a
```

### 基岩版注意

- 需要 OP 等级 1
- 旁观模式（spectator）从基岩版 1.19.50 开始可用，使用数字 `6`（Java 版中旁观模式数字为 `3`）
- 旁观模式下玩家可以自由飞行并穿过方块，但无法与世界中的方块、物品和实体进行交互
- 默认游戏模式可在世界设置中配置
