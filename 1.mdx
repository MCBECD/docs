```
/scoreboard objectives add online dummy §e在线时间§6（§b分§6）
```
创建名为在线时间的计分板


```
/scoreboard objectives setdisplay belowname online_time
```
将在线时间显示在玩家头上. 注：看不到自己的在线时间


<CmdRepeat>/scoreboard players add @a online_time 1</CmdRepeat>

循环无条件保持开启，延时1200

每秒增加所有玩家的在线时间
