## 命令语法基础

基岩版命令由命令名和参数组成。掌握语法约定、目标选择器和坐标系统是使用命令的基础。

### 语法约定

| 符号 | 含义 | 示例 |
|------|------|------|
| `<参数>` | 必填参数 | `<player: target>` 必须指定 |
| `[参数]` | 可选参数 | `[amount: int]` 可省略 |
| `a\|b` | 二选一 | `eyes\|feet` 选其一 |

以 [`/give`](./give) 为例：`/give <player: target> <itemName: Item> [amount: int] [data: int] [components: json]`——玩家和物品必填，其余可选。

### 目标选择器

| 选择器 | 说明 |
|--------|------|
| `@p` | 最近的玩家（默认 1 个） |
| `@a` | 所有玩家 |
| `@r` | 随机玩家（默认 1 个） |
| `@s` | 命令执行者自身 |
| `@e` | 所有实体（包括非玩家） |

### 选择器参数

在 `@选择器` 后方括号内添加参数，多个参数用逗号分隔：`@e[type=zombie,r=10,tag=!boss]`

| 参数 | 说明 | 示例 |
|------|------|------|
| `type=` | 实体类型 | `@e[type=cow]` |
| `r=` | 最大半径 | `@a[r=10]` |
| `rm=` | 最小半径 | `@a[rm=5]` |
| `m=` | 游戏模式 | `@a[m=survival]` |
| `name=` | 实体名称 | `@e[name=Steve]` |
| `tag=` | 实体标签 | `@e[tag=boss]`；`tag=!boss` 排除该标签 |
| `x=` `y=` `z=` | 坐标中心 | `@a[x=0,y=64,z=0,r=20]` |
| `dx=` `dy=` `dz=` | 体积选择（各轴延伸距离） | `@e[dx=5,dy=3,dz=5]` |
| `c=` | 数量限制 | `@a[c=3]` 最近的 3 个玩家 |
| `family=` | 实体家族 | `@e[family=mob]` |

**用法示例：**

[`/tp @a 0 64 0`](./tp) — 传送所有玩家

[`/effect @a[r=10] speed 30 1`](./effect) — 给 10 格内玩家加速

[`/kill @e[type=zombie]`](./kill) — 清除所有僵尸

[`/give @a[c=1,m=survival] diamond 1`](./give) — 给最近的生存模式玩家钻石

### 坐标系统

基岩版支持三种坐标格式：

| 类型 | 格式 | 说明 |
|------|------|------|
| 绝对坐标 | `100 64 100` | 世界中的精确位置 |
| 相对坐标 | `~ ~1 ~` | 相对于执行位置的偏移（`~` 表示当前值，可省略写为 `~ ~ ~`） |
| 局部坐标 | `^ ^ ^1` | 相对于执行者视线方向（`^` 前后、`^1` 左右、`^2` 上下），需用 `/execute anchored` 设置锚点 |

**用法示例：**

[`/setblock ~ ~-1 ~ diamond_block`](./setblock) — 脚下放钻石块

[`/fill ~-5 ~-1 ~-5 ~5 ~-1 ~5 stone`](./fill) — 铺 11×11 石头地板

[`/execute anchored eyes run particle minecraft:basic_flame_particle ^ ^1 ^`](./execute) — 眼睛前方 1 格发射火焰粒子

### 命令组合

用 [`/execute`](./execute) 在不同上下文中执行命令：

```mcfunction
/execute as @a at @s run setblock ~ ~-1 ~ gold_block
```

配合 [`/gamerule`](./gamerule) 控制世界规则：

```mcfunction
/gamerule keepInventory true
```

### 基岩版与 Java 版命令差异

| 特性 | 基岩版 | Java 版 |
|------|--------|---------|
| `/data` 命令 | ❌ 不支持 | ✅ 支持 |
| `/loot` 命令 | ❌ 不支持 | ✅ 支持 |
| `/item` 命令 | ❌ 不支持 | ✅ 支持 |
| `/execute store` | ❌ 不支持 | ✅ 支持 |
| 命令返回值 | 整数（0, 1, 2...） | 整数（1=成功, 0=失败） |
| NBT 数据操作 | 无直接命令 | 通过 `/data` |
| 物品组件 | JSON 格式 | NBT 格式 |
| 目标选择器 | 参数较少 | 更多参数 |
| `@initiator` 选择器 | ✅ 支持（NPC 交互） | ❌ 不支持 |

### 其他注意

- 命令方块中输入命令**不需要**前导斜杠 `/`
- 聊天栏中输入命令**需要**前导斜杠 `/`
- 返回值使用整数（如 0、1、2），0 通常表示成功
- 部分命令在基岩版中的语法和功能与 Java 版不同
- 查看所有命令见 [命令目录](./commands-reference)
