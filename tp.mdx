## `/tp` — 传送

传送实体（玩家、生物、掉落物等）到指定坐标或目标实体所在位置。

### 语法

**传送到实体：**

`/tp <victim: target> <destination: target>`

**传送到坐标（可指定朝向）：**

`/tp <victim: target> <x: value> <y: value> <z: value> [yRot: value] [xRot: value]`

**将执行者传送到实体：**

`/tp <destination: target>`

**将执行者传送到坐标（可指定朝向）：**

`/tp <x: value> <y: value> <z: value> [yRot: value] [xRot: value]`

### 参数

- `victim: target` — 被传送的实体。若未指定，默认为命令执行者自身。
- `destination: target` — 传送的目标实体，被传送的实体将移动到该实体的位置。
- `x: value` — 目标位置的 X 坐标。
- `y: value` — 目标位置的 Y 坐标。
- `z: value` — 目标位置的 Z 坐标。
- `yRot: value`（可选）— 传送后的水平旋转角度（yaw），范围 -180 到 180。正值表示向南偏转，负值表示向北偏转。
- `xRot: value`（可选）— 传送后的垂直旋转角度（pitch），范围 -90 到 90。正值表示向下看，负值表示向上看。

### 示例

**将所有玩家传送到执行者位置：**

```
/tp @a @s
```

**将最近玩家传送到坐标 (100, 64, 100)：**

```
/tp @p 100 64 100
```

**将自己传送到出生点：**

```
/tp 0 64 0
```

**将执行者向上传送 5 格并面朝南方（yRot=90）：**

```
/tp @s ~ ~5 ~ 90 0
```

**将所有玩家传送到当前位置并强制朝上（xRot=90）：**

```
/tp @a ~ ~ ~ 0 90
```

### 坐标说明

| 类型 | 格式 | 说明 |
|------|------|------|
| 绝对坐标 | `100 64 100` | 世界中的精确位置 |
| 相对坐标 | `~ ~1 ~` | 相对于当前位置偏移 |
| 局部坐标 | `^ ^ ^1` | 相对于当前视线方向偏移 |

### 基岩版注意

- 需要 OP 等级 1
- 实体必须处于已加载的区块中，否则传送可能失败
- 传送到实体时，默认保持被传送实体原有的朝向角度
- 可通过 `yRot` 和 `xRot` 参数控制传送后的朝向
- 传送到 Y 轴负值位置或超出世界高度限制会导致命令失败
- 大量实体同时传送可能造成性能问题
