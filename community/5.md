玩家互传（TPA）让任意两名玩家互相发起传送请求：一方在菜单里选中目标玩家，另一方抬头同意即可传送，低头或超时则取消。本文档整理自社区分享的命令组，并补充了原理解释。

> 如果你只需要「发起 → 接受 → 传送」的简化版，可参考 [`/docs/community/3/`](../3/)（雪球菜单）中的发起/接受传送部分。

### 原理解释

**三个核心状态**

- `cai`（菜单光标）—— 记录每位玩家「当前在菜单里做什么」：
  - `40` = 菜单基态（已打开、未选中任何行）
  - `41`~`50` = 正在浏览列表第 1~10 行
  - `51` = 选中「刷新列表」
  - `100` = 已被选为传送目标（等待回应）
  - `101` = 已接受请求（接受方）
  - `1000`+ = 取消/超时标记，`2000` = 清理标记
  - `5` = 从上级菜单选中「互传」后的入口状态（指令 1 把它归位成 `40`）

- `传送`（配对 ID）—— 每位玩家的「槽位号」：
  - `0`~`39` = 在线玩家的列表编号（第 0 位、第 1 位……）
  - `40`+ = 已发起请求的玩家（持有正槽位）
  - `-40`- = 等待回应的目标（持有负槽位）

  发起方和目标持有**同一个槽位号**，只是目标取反：谁把正负相加抵消成 `0`，谁就是发起方，用这一个数记住「谁和谁是一对」。

- `rx`/`rxm`（视角）—— 抬头 `rx=-88` = 确认/选择，低头 `rxm=88` = 拒绝/取消，与 [`雪球菜单`](../3/) 一致。

**+41 位移技巧**

列表第 1 行对应 `cai=41`，而这一行玩家的槽位号是 `0`，中间正好差 41。选择时先 `add @a 传送 41`（指令 7）把所有人整体 +41，于是第 N 行玩家的槽位临时变成 `41+N`，恰好等于他的 `cai`。这样就能用 `if score @s 传送 = @s cai` 判断「选的是不是自己」（指令 8），用 `if score @s 传送 = @p[...] cai` 找出被点中的目标（指令 9~11）。判断完 `remove @a 传送 41`（指令 13）还原。

**配对与接受**

发起请求后：目标从 `互传记录` 领一个新槽位（指令 14），发号器 +1（指令 15），发起方抄下同一个槽位（指令 16），目标再取反为负（指令 18）。接受时目标抬头 → `cai=101`（指令 43），把目标的负槽位加到所有人（指令 44）：发起方的正槽位被抵消成 `0`，于是 `tp @a[scores={传送=0}]` 精确命中发起方并传送到目标（指令 45），最后用相反操作撤销（指令 48）。

**为什么用「假玩家」计数器**

`互传记录`（发号器）、`负`（常量 -1，用于取反）、`检测`/`在线人员`/`互传`（一致性检查，清理离线玩家残留的配对）。用假玩家（fake player）而不是实体，是因为它们永远存在、不占实体，且分数能直接参与 `scoreboard players operation` 运算。

### 前置指令

在聊天栏中依次执行（创建计分板与常量）：

```
/scoreboard objectives add cai dummy
/scoreboard objectives add 传送 dummy
/scoreboard players set 负 传送 -1
/scoreboard players set 互传记录 传送 40
```
```
/gamerule commandblockoutput false
```
```
/gamerule sendcommandfeedback false
```

> `负` 是常量 -1（用于取反标记）；`互传记录` 是配对槽位发号器，从 40 起发，避免与列表编号 0~39 冲突。

### 命令方块摆放

以下每条均为**循环/无条件/保持开启**命令方块，按分组顺序摆放（同一组内顺序即执行顺序）。条件判断都写在 `execute` 的 `if`/`unless` 里，命令方块本身不需要「有条件」模式。

<CmdRepeat>`/scoreboard players add @a 传送 0`

#### 二、选择目标并发起请求

> 以下 `x=0,y=0,z=0` 为命令方块所在坐标的占位符，请替换为命令方块实际坐标。

**指令 7** — 全体槽位 +41 位移（把行号对齐到槽位号）

<CmdRepeat>`/execute as @p[scores={cai=41..50},rx=-88,x=0,y=0,z=0] run scoreboard players add @a 传送 41`

**指令 8** — 检测「自己传自己」

<CmdRepeat>`/execute as @p[scores={cai=41..50},rx=-88,x=0,y=0,z=0] if score @s 传送 = @s cai run tellraw @s {"rawtext":[{"text":"§c▎§r 玩家互传 §7不可以向自己申请互传"}]}`

**指令 9** — 告知发起方已发送请求

**指令 10** — 告知目标收到请求

<CmdRepeat>`/execute as @p[scores={cai=41..50},rx=-88,x=0,y=0,z=0] unless score @s 传送 = @s cai as @a if score @s 传送 = @p[scores={cai=41..50},rx=-88,x=0,y=0,z=0] cai run tellraw @s {"rawtext":[{"text":"§b▎§r 玩家互传 §7玩家§e"},{"selector":"@p[scores={cai=41..50},rx=-88,x=0,y=0,z=0]"},{"text":"§7向你发出互传申请\n §a抬头同意 §7- §c低头拒绝"}]}`

**指令 12** — 目标不存在时提示

<CmdRepeat>`/execute as @p[scores={cai=41..50},rx=-88,x=0,y=0,z=0] unless score @s 传送 = @s cai unless entity @a[scores={cai=100}] run tellraw @s {"rawtext":[{"text":"§c▎§r 玩家互传 §7你要申请的玩家不存在"}]}`

#### 三、配对记录

**指令 14** — 目标领新槽位

<CmdRepeat>`/execute as @a[scores={cai=100}] run scoreboard players operation @s 传送 = 互传记录 传送`

**指令 15** — 发号器 +1

<CmdRepeat>`/execute as @a[scores={cai=100}] run scoreboard players add 互传记录 传送 1`

**指令 16** — 发起方抄下同一槽位

<CmdRepeat>`/scoreboard players operation @p[scores={cai=41..50},rx=-88,x=0,y=0,z=0] 传送 = @a[scores={cai=100}] 传送`

**指令 17** — 无目标时重置光标

<CmdRepeat>`/execute as @p[scores={cai=41..50},rx=-88,x=0,y=0,z=0] unless entity @a[scores={cai=100}] run scoreboard players set @s cai 40`

**指令 18** — 目标槽位取反（标记等待回应）

<CmdRepeat>`/scoreboard players operation @a[scores={cai=100}] 传送 *= 负 传送`

#### 四、一致性维护与离线清理

**指令 19** — 检测计数器归零

<CmdRepeat>`/scoreboard players set 检测 传送 0`

**指令 20** — 统计槽位 0 的玩家数

<CmdRepeat>`/execute as @a[scores={传送=0}] run scoreboard players add 检测 传送 1`

**指令 21** — 槽位 0 重复 → 标记为 -1

<CmdRepeat>`/execute if score 检测 传送 matches 2..40 run scoreboard players set @a[scores={传送=0..39}] 传送 -1`

**指令 22** — 槽位重复 → 扣除修正

<CmdRepeat>`/execute if score 检测 传送 matches 2..40 run scoreboard players operation @a[scores={传送=-1..39}] 传送 -= @a[scores={传送=-1}] 传送`

**指令 23** — 槽位重复 → 重置光标

<CmdRepeat>`/execute if score 检测 传送 matches 2..40 run scoreboard players set @a[scores={cai=41..52,传送=0..39}] cai 40`

**指令 24** — 在线人数计数器归零

<CmdRepeat>`/scoreboard players set 在线人员 传送 0`

**指令 25** — 统计在线人数

<CmdRepeat>`/execute as @a[scores={传送=0..39}] run scoreboard players add 在线人员 传送 1`

**指令 26** — 在线人数计数器归零（重复）

<CmdRepeat>`/scoreboard players set 在线人员 传送 0`

**指令 27** — 统计在线人数（重复）

<CmdRepeat>`/execute as @a[scores={传送=0..39}] run scoreboard players add 在线人员 传送 1`

**指令 28** — 在线人数变化 → 标记为 -1

<CmdRepeat>`/execute unless score 互传 传送 = 在线人员 传送 run scoreboard players set @a[scores={传送=0..39}] 传送 -1`

**指令 29** — 在线人数变化 → 扣除修正

<CmdRepeat>`/execute unless score 互传 传送 = 在线人员 传送 run scoreboard players operation @a[scores={传送=-1..39}] 传送 -= @a[scores={传送=-1}] 传送`

#### 五、取消 / 拒绝 / 离线

**指令 30** — 目标低头 → 已拒绝提示

<CmdRepeat>`/tellraw @a[scores={传送=..-40},rxm=88] {"rawtext":[{"text":"§c▎§r 玩家互传 §7已拒绝对方的互传申请"}]}`

**指令 31** — 发起方低头 → 已取消提示

<CmdRepeat>`/tellraw @a[scores={传送=40..},rxm=88] {"rawtext":[{"text":"§c▎§r 玩家互传 §7已取消互传"}]}`

**指令 32** — 低头重置分数

<CmdRepeat>`/scoreboard players set @a[scores={传送=!0..39},rxm=88] 传送 0`

**指令 33** — 取消者标记 `cai=1000`

<CmdRepeat>`/scoreboard players add @r[scores={传送=!0..39}] cai 1000`

**指令 34** — 抵消取消者分数

<CmdRepeat>`/execute as @a[scores={cai=1000..}] run scoreboard players operation @a[scores={cai=!1000..}] 传送 += @s 传送`

**指令 35** — 抵消取消者分数（重复）

<CmdRepeat>`/execute as @a[scores={cai=1000..}] run scoreboard players operation @a[scores={cai=!1000..}] 传送 += @s 传送`

**指令 36** — 发起方侧：对方拒绝/离线提示

<CmdRepeat>`/execute as @a[scores={cai=1000..,传送=40..}] unless entity @a[scores={传送=0}] run tellraw @s {"rawtext":[{"text":"§c▎§r 玩家互传 §7对方拒绝互传或离线"}]}`

**指令 37** — 目标侧：对方取消/离线提示

<CmdRepeat>`/execute as @a[scores={cai=1000..,传送=..-40}] unless entity @a[scores={传送=0}] run tellraw @s {"rawtext":[{"text":"§c▎§r 玩家互传 §7对方取消互传或离线"}]}`

**指令 38** — 未配对成功 → 追加标记

<CmdRepeat>`/execute as @a[scores={cai=1000..}] unless entity @a[scores={传送=0}] run scoreboard players add @s cai 1000`

**指令 39** — 撤销抵消

<CmdRepeat>`/execute as @a[scores={cai=1000..}] run scoreboard players operation @a[scores={cai=!1000..}] 传送 -= @s 传送`

**指令 40** — 清理 `cai=2000` 残留

<CmdRepeat>`/scoreboard players set @a[scores={cai=2000..}] 传送 0`

**指令 41** — 移除取消标记

<CmdRepeat>`/scoreboard players remove @a[scores={cai=1000..}] cai 1000`

#### 六、接受并传送

**指令 42** — 清理旧状态

<CmdRepeat>`/scoreboard players set @a[scores={cai=100..}] cai 0`

**指令 43** — 目标抬头 → 接受（`cai=101`）

<CmdRepeat>`/scoreboard players set @p[scores={传送=..-40},rx=-88] cai 101`

**指令 44** — 抵消配对（发起方分数归 0）

<CmdRepeat>`/execute as @p[scores={cai=101}] run scoreboard players operation @a[scores={cai=!101}] 传送 += @s 传送`

**指令 45** — 执行传送

<CmdRepeat>`/tp @a[scores={传送=0}] @p[scores={cai=101}]`

**指令 46** — 告知接受方

<CmdRepeat>`/tellraw @p[scores={cai=101}] {"rawtext":[{"text":"§a▎ §f玩家互传 §7已接受§e"},{"selector":"@a[scores={传送=0}]"},{"text":"§7的互传申请"}]}`

**指令 47** — 告知发起方

<CmdRepeat>`/execute as @p[scores={cai=101}] run tellraw @a[scores={传送=0}] {"rawtext":[{"text":"§a▎§f 玩家互传 §7已将您传送至§e"},{"selector":"@s"}]}`

**指令 48** — 撤销抵消

<CmdRepeat>`/execute as @p[scores={cai=101}] run scoreboard players operation @a[scores={cai=!101,传送=!0}] 传送 -= @s 传送`

**指令 49** — 重置接受方分数

<CmdRepeat>`/scoreboard players set @p[scores={cai=101}] 传送 0`

### 常见问题

<details>
<summary>为什么「自己传自己」会被拒绝？</summary>

指令 8 用 `if score @s 传送 = @s cai` 检测选中行是否对应自己，若为自己则提示「不可以向自己申请互传」。这是通过 +41 位移后比较「自己的槽位」与「自己的光标」实现的。

</details>

<details>
<summary>为什么点列表没反应 / 提示玩家不存在？</summary>

多半是 `x=0,y=0,z=0` 没改：这是命令方块所在坐标的占位符，请替换为命令方块实际坐标（选择类指令 7~17 都有这个条件）。

</details>

<details>
<summary>为什么有两段看起来相同的指令？</summary>

原帖在「抵消分数」「统计在线人数」处疑似复制重复（指令 34/35、26/27）。本文按原文保留以与原系统行为一致；若实际使用中发现分数被多加/多减一次，可删掉重复的那一条。

</details>

<details>
<summary>离线玩家会残留导致列表错乱吗？</summary>

系统用 `检测`/`在线人员` 两个假玩家计数做一致性检查：槽位 0 重复、在线人数变化时，把受影响玩家的 `传送` 标记为 -1 并扣除修正（指令 19~29）。其中 `互传`（在线人数基准）在原系统中由上级菜单维护，独立使用时需自行更新该基准值。

</details>

<details>
<summary>标题里的「织梦菜单」能改吗？</summary>

可以，那是原作者的菜单名，纯展示文案。把指令 4 里的 `织梦菜单` 替换成你服务器的名字即可，不影响逻辑。

</details>

### 基岩版注意

- 全部为基岩版语法：`titleraw`/`actionbar`/rawtext、`scoreboard players operation` 的 `><`（交换）、`*=`（乘）等运算、以及 selector 里的 `scores={传送=!0..39}`（`!` 表示「非」，即分数不在该区间）均为基岩版特有写法
- `x=0,y=0,z=0` 需替换为命令方块实际坐标，否则带该条件的指令不会命中
- 涉及 [`/scoreboard`](../../commands/scoreboard/)、[`/execute`](../../commands/execute/)、[`/tp`](../../commands/tp/)、`/tellraw`、[`/title`](../../commands/title/)、[`/gamerule`](../../commands/gamerule/) 均需 OP 权限
- 本组指令原为「织梦菜单」系统的互传模块：入口状态 `cai=5` 与在线人数基准 `互传` 由上级菜单维护，独立使用时需自行补齐这两处
