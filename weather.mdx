## `/weather` — 天气控制

设置或查询世界的天气状况。

### 语法

`weather <weatherType: WeatherType> [duration: int]`

`weather query`

### 参数

- `<weatherType: WeatherType>` — 要设置的天气类型。

| 天气类型 | 说明 |
|----------|------|
| `clear` | 晴天 — 清除所有降雨和雷暴效果 |
| `rain` | 下雨 — 降水天气，会形成水坑（部分生物群系） |
| `thunder` | 雷暴 — 降雨并伴有闪电 |

- `[duration: int]`（可选）— 天气持续的时长，单位为**游戏刻**（tick）。1 秒 = 20 刻。若不指定，则持续时长为随机值（通常为 3000–6000 刻，即 2.5–5 分钟）。最大值为 1000000 刻（约 13.9 小时真实时间），超过该值会被截断。

- `query` — 查询当前天气的剩余持续时间（以游戏刻为单位），结果显示在聊天栏中。

### 示例

**设置为晴天：**

```
/weather clear
```

**设置 5 分钟的下雨（6000 刻）：**

```
/weather rain 6000
```

**设置为雷暴天气：**

```
/weather thunder
```

**近似永久晴天（1000000 刻 ≈ 13.9 小时）：**

```
/weather clear 1000000
```

**查询当前天气剩余时间：**

```
/weather query
```

**设置 10 秒的雷暴（200 刻）：**

```
/weather thunder 200
```

### 基岩版注意

- 需要 OP 等级 1
- 持续时间单位为**游戏刻**（tick），不是秒。1 秒 = 20 刻
- 不指定持续时间时，游戏会随机决定天气持续时长
- `weather query` 可查询当前天气的剩余刻数
- 晴天也会自然结束，使用 1000000 刻可近似实现
