## `/title` — 屏幕标题

在玩家屏幕上显示标题、副标题或操作栏文字。`/titleraw` 变体使用 JSON rawtext 格式发送格式化文本。

### 语法

#### `/title`

```mcfunction
title <player: target> title <titleText: message>
title <player: target> subtitle <titleText: message>
title <player: target> actionbar <titleText: message>
title <player: target> times <fadeIn: int> <stay: int> <fadeOut: int>
title <player: target> clear
```

#### `/titleraw`

```mcfunction
titleraw <player: target> title <rawText: json>
titleraw <player: target> subtitle <rawText: json>
titleraw <player: target> actionbar <rawText: json>
titleraw <player: target> times <fadeIn: int> <stay: int> <fadeOut: int>
```

### 参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `player: target` | 目标选择器 | 要显示标题的玩家 |
| `titleText: message` | 字符串 | 标题文字，支持 `§` 格式化代码 |
| `rawText: json` | JSON | 使用 rawtext 格式的格式化文本 |
| `fadeIn: int` | 整数 | 淡入时间（刻） |
| `stay: int` | 整数 | 停留时间（刻） |
| `fadeOut: int` | 整数 | 淡出时间（刻） |
| `clear` | — | 立即清除屏幕上的标题 |

### 默认时间

| 阶段 | 默认值 | 换算 |
|------|--------|------|
| 淡入 | 10 刻 | 0.5 秒 |
| 停留 | 70 刻 | 3.5 秒 |
| 淡出 | 20 刻 | 1.0 秒 |

1 秒 = 20 刻。

### 示例

**显示简单标题：**
```mcfunction
/title @p title 欢迎来到服务器！
```

**显示带副标题的标题（先设副标题再设主标题）：**
```mcfunction
/title @p subtitle 恭喜通关！
/title @p title Boss 被击败了！
```

**在操作栏显示消息：**
```mcfunction
/title @p actionbar §a§l你发现了秘密！
```

**自定义时间后显示标题（必须在显示之前设置）：**
```mcfunction
/title @p times 30 100 20
/title @p title §6第 1 轮
```

**使用 `/titleraw` 发送 JSON rawtext：**
```mcfunction
/titleraw @p title {"rawtext":[{"text":"","color":"red","bold":true},{"text":" 警报！"}]}
```

**清除标题：**
```mcfunction
/title @p clear
```

### `/title` 与 `/titleraw` 的区别

| 特性 | `/title` | `/titleraw` |
|------|----------|-------------|
| 文本格式 | 纯文本 + `§` 格式化代码 | JSON rawtext 格式 |
| `times` 子命令 | ✅ 支持 | ✅ 支持 |
| `clear` 子命令 | ✅ 支持 | ❌ 不支持 |
| `times` 设置时间 | 对两者生效 | 对两者生效 |

### 基岩版注意

- **时间必须先设置**：`times` 必须在显示标题（`title`/`subtitle`/`actionbar`）**之前**调用，否则使用默认时间
- `/title` 的 `titleText: message` 参数支持 `§` 格式化代码（如 `§c` 红色、`§l` 粗体）
- `/titleraw` 的 `rawText: json` 参数使用基岩版 rawtext JSON 格式，不支持 `§` 代码
- `times` 设置的时间对 `/title` 和 `/titleraw` 都生效，只需设置一次
- 操作栏（actionbar）文字显示在快捷栏上方
- 基岩版没有 `reset` 子命令（Java 版有）
- 需要 OP 等级 1
