## `/kill` — 清除实体

清除（杀死）实体，包括玩家、生物、掉落物等。对玩家造成致命伤害，对非玩家实体直接移除。

### 语法

`/kill [target: target]`

### 参数

- `target: target`（可选）— 要清除的实体目标选择器。若未指定，默认为命令执行者自身（即自杀）。

### 示例

**清除所有苦力怕：**

```
/kill @e[type=creeper]
```

**清除所有掉落物：**

```
/kill @e[type=item]
```

**清除自己：**

```
/kill
```

### 基岩版注意

- 需要 OP 等级 1
- 对玩家造成致命伤害，玩家会被正常击杀（显示死亡消息，产生掉落物）
- 对非玩家实体（生物、掉落物等）直接移除，不产生掉落物和死亡动画
- 不指定目标时默认清除执行者自身
- 在没有实体匹配目标选择器时，命令会报错提示"没有找到目标"
- 使用 `@e[type=item]` 可清除地上所有掉落物
- 使用 `@e[type=!player]` 可清除所有非玩家实体（注意：慎用，可能误删重要实体）
