## `/particle` — 粒子效果

在指定位置创建粒子效果。

### 语法

`particle <effect: Particle> [position: x y z] [count: int]`

### 参数

- `<effect: Particle>` — 粒子效果标识符
- `[position: x y z]` — 坐标（默认为命令执行位置）
- `[count: int]` — 粒子数量

### 常用粒子效果

| 粒子效果 ID | 说明 |
|-------------|------|
| `minecraft:basic_flame_particle` | 火焰粒子 |
| `minecraft:smoke_particle` | 烟雾粒子 |
| `minecraft:cloud_particle` | 云朵粒子 |
| `minecraft:enchanting_table_particle` | 附魔符文粒子 |
| `minecraft:heart_particle` | 飘浮爱心 |
| `minecraft:angry_villager_particle` | 愤怒的村民粒子 |
| `minecraft:villager_happy_particle` | 开心的村民粒子 |
| `minecraft:portal_directional` | 传送门粒子 |
| `minecraft:end_rod` | 末地烛粒子 |
| `minecraft:dust_particle` | 灰尘粒子 |
| `minecraft:splash_particle` | 水花飞溅 |
| `minecraft:lava_particle` | 熔岩滴落 |
| `minecraft:campfire_smoke_particle` | 营火烟雾 |
| `minecraft:totem_particle` | 不死图腾粒子 |
| `minecraft:dragon_breath_particle` | 末影龙吐息 |
| `minecraft:falling_dust_particle` | 下落灰尘 |
| `minecraft:underwater_torch_particle` | 水下火把粒子 |

### 示例

**在自己位置创建爱心粒子：**
```mcfunction
/particle minecraft:heart_particle ~ ~ ~
```

**创建大量火焰粒子效果：**
```mcfunction
/particle minecraft:basic_flame_particle ~ ~ ~ 50
```

**在最近玩家上方创建烟雾：**
```mcfunction
/particle minecraft:smoke_particle ~ ~2 ~
```

**创建附魔粒子效果：**
```mcfunction
/particle minecraft:enchanting_table_particle ~ ~ ~ 30
```

**在坐标处创建传送门粒子：**
```mcfunction
/particle minecraft:portal_directional 50 70 50
```

### 基岩版注意

- 粒子效果在基岩版中**仅用于视觉效果**，不与实体交互，不影响游戏逻辑
- 粒子效果 ID 需使用基岩版专属 ID，与 Java 版不完全相同
- 大量粒子（超过数百个）可能导致性能问题，请适量使用
- 可与命令方块或 `/execute` 配合使用实现动画效果
- 需要 OP 等级 1
