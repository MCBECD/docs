## `/xp` — 经验值

给予、扣除玩家的经验值或经验等级。在基岩版中，`/xp` 仅支持给予或扣除经验，不支持设定或查询。

### 语法

**给予/扣除经验点数：**

`/xp <amount: int> [player: target]`

**给予/扣除经验等级：**

`/xp L <amount: int> [player: target]`

### 参数

- `amount: int` — 要给予或扣除的经验数量。正数表示给予，负数表示扣除。
- `L` — 等级标识符。加上 `L` 前缀表示操作的是经验**等级**而非经验**点数**。
- `player: target`（可选）— 目标玩家。若未指定，默认为命令执行者自身。

### 示例

**给自己 100 经验点数：**

```
/xp 100 @s
```

**给所有玩家 5 级经验：**

```
/xp L 5 @a
```

**给自己 30 级经验：**

```
/xp L 30
```

**扣除最近玩家 10 级经验：**

```
/xp L -10 @p
```

### 基岩版注意

- 需要 OP 等级 1
- 基岩版中 `/xp` 仅支持给予和扣除经验，**不支持** `set`（设定）和 `query`（查询）子命令
- `/experience` 是 `/xp` 的完整别名，两者功能完全相同
- 数量可以为负数，用于扣除经验
- 给予经验点数时会先填满当前等级，溢出部分会累加到下一级
- 扣除经验等级时，若当前等级不足，等级会被降到 0
