## `/gamerule` — 游戏规则

设置或查询世界的游戏规则。游戏规则控制世界的各种行为机制，修改后立即生效（部分规则需重新进入世界）。

### 语法

`gamerule <gameRuleName: BooleanGameRule> [value: Boolean]`

`gamerule <gameRuleName: IntGameRule> [value: int]`

不指定 `[value]` 时，命令将查询并返回该规则的当前值。

### 参数

- `<gameRuleName: BooleanGameRule>` — 布尔类型的游戏规则名称，值为 `true` 或 `false`。
- `<gameRuleName: IntGameRule>` — 整数类型的游戏规则名称，值为整数。
- `[value: Boolean]` — 布尔值，`true` 开启 / `false` 关闭。
- `[value: int]` — 整数值。

### 常用游戏规则

#### 布尔规则（BooleanGameRule）

| 规则 | 默认值 | 说明 |
|------|--------|------|
| `keepInventory` | `false` | 玩家死亡后保留物品栏和经验 |
| `doDaylightCycle` | `true` | 是否进行昼夜循环 |
| `doMobSpawning` | `true` | 是否生成生物 |
| `doFireTick` | `true` | 火焰是否蔓延和熄灭 |
| `mobGriefing` | `true` | 生物是否可以破坏方块（如苦力怕爆炸、末影人搬方块） |
| `showCoordinates` | `false` | 是否在屏幕上显示坐标（基岩版独有） |
| `commandBlocksEnabled` | `true` | 是否允许命令方块执行 |
| `doMobLoot` | `true` | 生物死亡时是否掉落物品 |
| `doTileDrops` | `true` | 方块被破坏时是否掉落物品 |
| `doEntityDrops` | `true` | 非生物实体被破坏时是否掉落物品 |
| `doWeatherCycle` | `true` | 天气是否自然循环 |
| `pvp` | `true` | 是否允许玩家间 PvP 伤害 |
| `naturalRegeneration` | `true` | 玩家是否自然恢复生命值（饥饿值足够时） |
| `showDeathMessages` | `true` | 是否在聊天栏显示死亡消息 |
| `tntExplodes` | `true` | TNT 是否能爆炸 |
| `sendCommandFeedback` | `true` | 命令执行结果是否在聊天栏反馈 |
| `maxCommandChainLength` | `65536` | 命令方块链的最大执行长度 |
| `commandBlockOutput` | `true` | 命令方块是否将输出写入聊天栏 |
| `doInsomnia` | `true` | 幻翼是否在玩家不睡觉时生成 |
| `respawnBlocksExplode` | `true` | 重生锚和床在错误维度是否爆炸 |
| `showTags` | `false` | 是否显示实体的标签 |

### 示例

**开启死亡不掉落：**

```
/gamerule keepInventory true
```

**锁定昼夜循环：**

```
/gamerule doDaylightCycle false
```

**显示坐标：**

```
/gamerule showCoordinates true
```

**禁止生物生成：**

```
/gamerule doMobSpawning false
```

**查询当前 keepInventory 状态：**

```
/gamerule keepInventory
```

**禁止苦力怕破坏方块：**

```
/gamerule mobGriefing false
```

**关闭 PvP：**

```
/gamerule pvp false
```

### 基岩版注意

- 需要 OP 等级 1（部分规则可能需要不同等级）
- `showCoordinates` 是基岩版独有规则，Java 版没有此规则
- `commandBlocksEnabled` 控制命令方块是否可被激活和执行
- 部分规则（如 `showCoordinates`）需要退出并重新进入世界才能完全生效
- 不带值查询规则时，结果会显示在聊天栏中
- 规则名称不区分大小写
- `maxCommandChainLength` 是整数规则，控制命令方块递归调用链的最大深度
