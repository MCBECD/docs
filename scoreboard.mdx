## `/scoreboard` — 计分板

管理计分板目标（objectives）、玩家分数和显示设置。计分板是基岩版中实现数据追踪、条件判断和复杂游戏逻辑的核心工具。

### 目标管理子命令

```mcfunction
scoreboard objectives add <name: string> dummy [displayName: string]
scoreboard objectives remove <name: string>
scoreboard objectives list
scoreboard objectives setdisplay <slot: DisplaySlot> [objective: string] [ascending|descending]
```

### 玩家分数子命令

```mcfunction
scoreboard players add <player: target> <objective: string> <count: int>
scoreboard players remove <player: target> <objective: string> <count: int>
scoreboard players set <player: target> <objective: string> <count: int>
scoreboard players reset <player: target> [objective: string]
scoreboard players list [player: target]
scoreboard players test <player: target> <objective: string> <min: wildcard> <max: wildcard>
scoreboard players operation <targetPlayer: target> <targetObjective: string> <operation: ScoreOperator> <sourcePlayer: target> <sourceObjective: string>
scoreboard players get <player: target> <objective: string>
```

### 参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `name: string` | 字符串 | 计分板目标名称，不含空格 |
| `displayName: string` | 字符串 | 显示名称（可选，支持 `§` 格式化代码） |
| `slot: DisplaySlot` | 枚举 | 显示栏位 |
| `player: target` | 选择器 | 目标玩家或实体（用 `*` 代表所有已追踪玩家） |
| `objective: string` | 字符串 | 计分板目标名称 |
| `count: int` | 整数 | 分数值 |
| `min/max: wildcard` | 通配符 | 最小/最大值，支持 `*` 表示无限制 |
| `operation: ScoreOperator` | 运算符 | 分数运算类型 |

### 显示栏位（DisplaySlot）

| 栏位 | 说明 |
|------|------|
| `sidebar` | 屏幕右侧列表 |
| `list` | Tab 列表中玩家名称旁 |
| `belowname` | 玩家名称标签下方 |

`setdisplay` 后可加 `ascending`（升序）或 `descending`（降序，默认）来控制排序方向。

### 运算符（ScoreOperator）

| 运算 | 说明 | 等价于 |
|------|------|--------|
| `=` | 设为源值 | `set` |
| `+=` | 加上源值 | `add` |
| `-=` | 减去源值 | `subtract` |
| `*=` | 乘以源值 | `multiply` |
| `/=` | 除以源值（整数除法） | `divide` |
| `%=` | 对源值取余 | `modulo` |
| `<` | 取两者较小值 | `min` |
| `>` | 取两者较大值 | `max` |
| `><` | 交换两者分数 | `swap` |

### 计分准则

| 准则 | 说明 | 类型 |
|------|------|------|
| `dummy` | 不自动计分，完全由命令控制 | 手动 |
| `deathCount` | 玩家死亡次数 | 自动（只读） |
| `playerKillCount` | 玩家击杀其他玩家次数 | 自动（只读） |
| `totalKillCount` | 总击杀数 | 自动（只读） |
| `health` | 生命值 | 自动（只读） |
| `xp` | 当前经验值 | 自动（只读） |
| `foodLevel` | 饥饿值 | 自动（只读） |
| `level` | 经验等级 | 自动（只读） |

### 示例

**创建计分板目标：**
```mcfunction
/scoreboard objectives add money dummy §e金币
```

**在侧边栏显示（降序）：**
```mcfunction
/scoreboard objectives setdisplay sidebar money descending
```

**给玩家加分：**
```mcfunction
/scoreboard players add @p money 10
```

**设置分数：**
```mcfunction
/scoreboard players set @p money 100
```

**查询分数：**
```mcfunction
/scoreboard players get @p money
```

**判断分数范围（50 到 100 之间）：**
```mcfunction
/scoreboard players test @p money 50 100
```

**判断分数范围（>= 100）：**
```mcfunction
/scoreboard players test @p money 100 *
```

**分数运算 — 将玩家 A 的分数加倍：**
```mcfunction
/scoreboard players operation @p money *= @s money
```

**两个玩家分数相加：**
```mcfunction
/scoreboard players operation Steve money += Alex money
```

**交换两个分数：**
```mcfunction
/scoreboard players operation @p temp >< @s money
```

**移除目标：**
```mcfunction
/scoreboard objectives remove money
```

**重置玩家某项分数：**
```mcfunction
/scoreboard players reset @p money
```

**重置玩家所有分数：**
```mcfunction
/scoreboard players reset @p
```

**列出所有已追踪玩家：**
```mcfunction
/scoreboard players list
```

**列出指定玩家的分数：**
```mcfunction
/scoreboard players list @p
```

### 基岩版注意

- 需要 OP 等级 1（部分子命令需要等级 2）
- `dummy` 准则最常用，不会自动计分，完全由命令控制
- 自动计分准则（如 `deathCount`、`playerKillCount`）的分数无法手动修改
- `health`、`xp`、`foodLevel`、`level` 等只读准则只能查询，不能设置
- 计分板值为整数，范围 -2,147,483,648 到 2,147,483,647
- 通配符 `*` 在 `test` 命令中表示无限制，在 `reset` 中代表所有已追踪玩家
- 显示名称支持 `§` 格式化代码
- 结合 `/execute if score` 进行条件逻辑判断
- `test` 命令返回值可用于条件判断：0 = 通过，1 = 最小值未达到，2 = 最大值已超过
