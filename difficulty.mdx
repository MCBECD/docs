## `/difficulty` — 难度设置

设置或查询世界的难度等级。难度影响怪物的生成、伤害、行为等核心游戏机制。

### 语法

`difficulty <difficulty: Difficulty>`

`difficulty`

不指定参数时，命令将返回当前世界的难度设置。

### 参数

- `<difficulty: Difficulty>` — 要设置的难度。支持以下三种格式：

| 全称 | 缩写 | 数字 | 说明 |
|------|------|------|------|
| `peaceful` | `p` | `0` | 和平 — 不生成敌对生物，玩家生命值自动恢复 |
| `easy` | `e` | `1` | 简单 — 敌对生物生成，伤害较低 |
| `normal` | `n` | `2` | 普通 — 标准难度，平衡的游戏体验 |
| `hard` | `h` | `3` | 困难 — 敌对生物伤害高，僵尸可破门， creeper 爆炸破坏方块 |

### 示例

**设为和平模式：**

```
/difficulty peaceful
```

**使用缩写设为简单难度：**

```
/difficulty e
```

**使用数字设为普通难度：**

```
/difficulty 2
```

**设为困难难度：**

```
/difficulty hard
```

**查询当前难度：**

```
/difficulty
```

### 基岩版注意

- 需要 OP 等级 1
- 难度支持全称、单字母缩写和数字三种写法
- 困难难度下僵尸可以破门
- 和平模式下已有的敌对生物不会立即消失，但不会继续生成新的
- 更改难度会立即影响所有玩家
- 难度也可在世界设置中永久更改
